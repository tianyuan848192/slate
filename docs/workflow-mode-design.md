# 工作流模式：设计（2026-10-17 评审通过并实现）

> 静态原型评审通过后已删除。实现和设计的差别见最后一节"实现说明"；接口见 `docs/api.md` 的"工作流模式"一节。

## 一、要做成什么样

新建页分两种模式：

- **自由模式**：就是现在的新建页，只改名。里面照旧有视频、3D 图片，快速、高级。
- **工作流模式**：一块无限画板。用户添加节点、连线，每个节点单独运行，并且可以在每个节点里单独和 Agent 聊天修改。做得好的工作流可以存下来，下次换描述和资料再跑。

**和自由模式的区别**：不是出片逻辑不同，而是**能在文字、图片、音画三个环节分别停下来，看产出、聊天修改**，满意了再往下走。

## 二、三种节点

```
[文字节点] ──────────────┐
  资料整理 → 剧本 → 分镜   │
  （写作风格作用于这里）    ├──→ [音画节点] ──→ 成片
                          │     配音 → 写画面 → 渲染 → 合成
[图片节点] × 0～3 ────────┘     （视觉风格、配音风格作用于这里）
  做一个 3D 图片（JS 代码）
  或者从素材库选一个
```

| 节点 | 卡片里设置什么 | 运行时做什么 | 卡片里看到的产出 | 聊天能改什么 |
|---|---|---|---|---|
| **文字** | 描述（必填）；资料（上传文件、素材库文件、链接，联网搜索，强制引用）；写作风格（现在的"写法"）；时长 | Agent 按原来的流程做前四步：资料整理、需求分析、写剧本、写分镜，然后停下 | 资料摘要、剧本（逐段）、分镜表（每镜旁白和画面）；可以直接改字 | 剧本和分镜：讲法、结构、某一镜的旁白和画面 |
| **图片** | 新做一个 3D：描述、0～4 张照片、拆解开关；或者从素材库选一个已有的 3D 图片 | 新做的就是现在的 3D 图片任务（单独一个会话） | 可旋转的模型预览、多角度图、拆解图 | 模型本身，和现在 3D 图片的修改一样 |
| **音画** | 视觉风格（主风格，最多加一个插入风格）；配音风格（音色、字幕开关、配乐）；画幅、分辨率、帧率 | Agent 按原来的流程做后三步：先配音，再写画面代码、渲染，最后合成 | 每镜小样、成片 | 画面和声音：某一镜的画面、节奏、配音、换风格，和现在修改成片一样 |

**连线规则**：
- 一个工作流：1 个文字节点，1 个音画节点，0～3 个图片节点（和现在视频最多引用 3 个 3D 图片一致）。
- 只能连"文字 → 音画"和"图片 → 音画"，其他连法画板不允许。

## 三、怎么运行（保持 Agent 原来的逻辑）

**文字节点和音画节点是同一个视频任务、同一个 Agent 会话**，只是中间多停一下。这正是现在"生成前确认分镜"的做法：写完分镜停下来，确认后接着配音、写代码、渲染、合成。工作区、分镜契约、会话都不变，所以音画同步和全片一致性和现在一样。

1. **运行文字节点**：
   - 建一个视频任务，"生成前确认分镜"强制打开；
   - Agent 做到分镜就停下，状态是"等你确认"；
   - 图片节点已经做好的话，模型从一开始就交给 Agent，写分镜时就能安排怎么拍。
2. **在文字节点聊天**：
   - 现在系统已经支持：停在"等你确认"时发消息，Agent 改剧本和分镜，改完仍然停在"等你确认"。
   - 工作流里这条消息只算文字节点的。
3. **运行图片节点**：就是现在的 3D 图片任务，和文字节点可以同时跑。
4. **运行音画节点**：
   - 要求文字节点已经完成，连着的图片节点也都做好了；
   - 运行就是现在的"确认分镜"，只多带两样东西：
     - 音画节点卡片里选的视觉风格、配音风格、画幅等设置，Agent 按"只换风格"的规则处理，讲稿和分镜不动；
     - 文字节点之后才做好的 3D 图片：复制进任务目录，告诉 Agent 可以按素材卡调整相关镜头的画面。
5. **在音画节点聊天**：就是现在的成片修改，比如"第 3 镜太空了"，改完出新版本。
6. **成片出来以后，回头在文字节点聊天**：
   - Agent 只改剧本和分镜，不配音、不渲染，改完停下；
   - 音画节点标成"需要重跑"；
   - 重跑音画时，只重新配音和渲染变了的镜头，没变的镜头直接复用，用的是现在的内容指纹机制。

**每个节点的聊天单独显示**：消息记录已经能带"范围"，用户的消息记上节点名；Agent 回的消息，按当时这一轮属于哪个节点，也记上节点名。节点卡片的聊天框只显示自己的消息。

## 四、保存工作流

- **"另存为我的工作流"**：存节点、连线和每个节点的设置，比如写作风格、视觉风格、配音风格、时长、画幅，不存产出。
- **从我的工作流新建**：设置都带上，换描述和资料就能跑。
- **工作流列表**：在工作流模式的首页，可以改名、删除。

## 五、要做的改动

## 六、第一版范围

- **做**：
  - 三种节点；
  - 每个节点单独运行和聊天；
  - 回头改文字后重跑音画；
  - 保存和复用工作流；
  - 自由模式改名。
- **不做（以后再说）**：
  - 一个工作流出多支视频，比如同时出横屏版、竖屏版；
  - 长片（超过 3 分钟）的工作流：长片先出总纲再分章，节点要怎么对应，单独设计；
  - 把工作流分享给别人。

## 七、成本和风险

- **每停一次，多一轮的上下文成本**：提示缓存只保留 5 分钟，停得久了要重新写缓存。每多停一次，按现在的单价大约多几毛钱到一块钱，以实测为准。
- **停太久，对话记录会丢**：会话空闲 30 分钟会被回收。工作区会从存档恢复，Agent 读文件接着做，现在隔很久改片子也是这样。
- **跨节点的修改有先后**：文字改了，音画必须重跑，画板上会明确标出"需要重跑"，不会悄悄用旧的。

## 八、实现说明（2026-10-17）

- **代码**：
  - 后端：`backend/lib/flows.py`（画板和我的工作流）、`api.py` 的 `flow_av`（音画节点）和 `_flow_node`（节点对话）、`turn.py` 的两种新提示（文字节点修改、音画节点重跑）、`events.py`（消息按节点记、成片版本记分镜指纹）；
  - 做片手册第 11 节"工作流模式"；
  - 前端：`web/js/flows.js`（首页）、`web/js/flow.js`（画板）、`web/js/flowdefs.js`（节点定义和模板）。
- **和原型不同的一处**：文字节点运行过以后，改了描述、资料、写作风格或时长再点"重新运行"，会**新建一个任务**，不在原任务里重写。原来的任务和成片照常留在"任务"页里。
  - 原因：这些设置一变，原来的配音和画面基本都用不上了；新建任务最简单，也不会把两套内容混在一个工作区里。
  - 只改剧本和分镜时，照常在文字节点里对话，任务不变。
- **"需要重跑"怎么判断**：每版成片记下当时每镜的指纹（旁白、画面描述、风格），之后分镜改了哪几镜和它一比就知道。音画节点的设置、连着的 3D 图片，和任务记录里的比。
- **画板的保存**：第一次运行节点时存到服务端，之后有改动就自动保存，任务页的"在画板里打开"能回到这里。"保存为工作流"存的是不带产出的模板，上传的文件和照片不进模板（上传记录会过期）；用素材库的文件和链接可以。
