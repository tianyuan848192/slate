# Slate 的 Skill 分类

2026-10-14 整理。原来自己做的 7 个风格（编辑图解、瑞士网格、霓虹擂台、界面秀、纸媒拼贴、窗花剪纸、水墨山水）已下架，移到 `agent/legacy-skills/`，老任务修改和重渲照常能加载。

## Skill 的分类

| 类别 | Skill | 谁用 | 用户能不能选 |
|---|---|---|---|
| 做片手册 | `core-director`（流程、格式、场景写法、动效原则，含 11 种**写法**和讲解类、宣传类的通用打法）、`film-kit`（影片风格在 Slate 里的用法） | Agent 每次必读；写法按任务选一种 | 写法在新建页单独选（快速、高级模式都有） |
| 风格 | 44 个：43 个影片风格 `film-*` + 机械图解 `anatomy` | 一支片子一个主风格，最多再加一个插入风格 | 新建页的风格库 |
| 素材库 | `kit-shots` 镜头模板 32 个、`kit-motion` 动作 30 个 | Agent 自动搭配任何风格 | 不展示 |

关系靠引用：做片手册引用素材库和风格，每个影片风格的说明开头引用 `film-kit`。各自独立登记给 Agent，按需打开，互不覆盖。

## 写法和风格互相独立（2026-10-15）

- **写法**决定剧本怎么组织：叙事结构、开场、镜头顺序、节奏和旁白语气。**风格**决定画面长什么样：配色、字体、版式和动作语言。任何写法都能配任何风格，比如"知识科普 + 像素游戏"。
- 写法 11 种，目录在 `agent/skills/genres.json`，每种的说明在 `agent/skills/core-director/genres/<id>.md`：
  - 讲解类（通用打法 `explainer-playbook.md`）：知识科普、原理讲解、教程步骤、清单盘点、故事案例、数据故事；
  - 宣传类（通用打法 `ad-playbook.md`）：产品介绍、新品发布、功能上新、品牌故事、促销活动。
- 用户选了写法，Agent 照着写，brief 的类型以用户的为准（服务端发布时会改正）；没选时 Agent 按内容挑一种。
- 每种写法有一份"常搭配"的风格清单，只用来在风格库里排序和标记，**不限制选择**。用户没选风格时，用清单里的第一个作为默认风格。
- 冲突时：剧本结构、镜头顺序和旁白听写法的；画面版式、配色、动作和镜头内部的节奏听风格的。
- 修改时可以只换风格（讲稿、旁白和配音保留，画面重做），也可以只换写法（重写讲稿和分镜，风格不变）。

## 用户看到的两类：写作方法和画风（2026-10-18）

- 网页上统一叫**写作方法**（就是上面的写法）和**画风**（就是上面的风格），Agent 用的手册里还叫写法、风格，内容不变。
- 两类都有内置的和管理员生成的。生成的由管理端"Skill 创建"反编译参考视频得到，一段视频可以同时出一种画风（`film-<短名>`）和一种写作方法（`write-<短名>`），分开验证、分开发布。说明见 `docs/skills-two-dimensions.md`。
- 生成的写作方法：接口 `GET /api/skills` 的 `genres` 里和内置的排在一起，带 `generated: true`；内测中的带 `beta: true`，只返回给管理员。新建页和工作流文字节点的下拉框里标"（内测）"，Skills 页标"内测"。
- 建任务时复制进任务的 `input/writing/<id>/`，Agent 按任务说明里 `genre.guide` 读它，再按 `genre.group` 读讲解类或宣传类的通用打法。

## 一支片子用多个 Skill 的规则

- **主风格**一个，决定全片的配色、字体、字幕样式和动作语言。用户选的第一个是主风格；没选时用写法的默认风格。
- **插入风格**最多一个，只做有意为之的"片中片"：插入的镜头集中在一起，前后留过渡，**同一镜不能混用两个风格**（两个风格都会占满画面、各自定义 `render(t)`、改页面背景和字幕样式）。
- **素材库**随便用，配色和字体换成主风格的；主风格是"一拍两帧"的手绘类风格时，动作也取整到 1/12 秒。
- **字幕全片统一**：分镜的 `caption_style`（长片写在总纲的 `look.caption_style`），渲染时盖过每一镜自己的字幕样式。
- 系统检查：前端最多选两个风格；`slate-publish storyboard` 和后端都会拒绝用到三个以上风格的分镜。
