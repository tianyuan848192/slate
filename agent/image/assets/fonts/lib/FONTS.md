# 可用字体（Google Fonts，开源许可）

在场景页里引用对应的 CSS，例如 `<link rel="stylesheet" href="/assets/fonts/lib/archivo.css">`，
然后在 CSS 或画布里用字体家族名。字体按字符范围切片，只会加载用到的那几片。
