# 纸媒拼贴

把一支讲解片做成"会动的杂志跨页"：几张剪下来的纸片落在旧报纸上，一边讲一边圈、一边盖章、一边贴纸条。判断标准：**定格任意一帧，像一页认真排过的图解报道。**

## 是什么 / 不是什么

- **是**：
  - 有纸的质感：纸纹、撕口的白芯、软投影、胶带、图钉、红线；
  - 照片是剪下来的，带白边，统一做成墨色双色调或网点印刷；
  - 强调靠"手"：马克笔圈注、手写批注、印章、荧光笔；
  - 每个数据画面都有来源标签。
- **不是**：
  - 不是编辑图解（editorial 是发丝线和铅笔稿逐步上墨，这里是纸片落下、贴上）；
  - 不是扁平信息图（没有渐变、没有圆角卡片、没有图标库）；
  - 不是国潮剪纸（不用中国红大面积铺底，不做团花和镂空）；
  - 不是霓虹科技风（不发光、不用暗色渐变，暗场变体也只是"深色纸"）。

## 画面

### 纸张与质感

- **底纸**（`CL.stage({ paper })`），一支片只用一种：
  - `cream`：旧报纸，默认；
  - `newsprint`：新闻纸，偏灰；
  - `kraft`：牛皮纸，做"案卷"变体，适合辟谣、调查、历史档案；
  - `dark`：新闻暗场，适合夜间突发、悬疑感的开场。
- 纸纹由程序生成（确定性噪声），锚定在世界坐标：镜头移动时纸纹跟着走，不会"游泳"。
- 颗粒每 2 帧换一次，强度用 `grain` 调（0～1）。
- `fold: true` 加一道对折痕，适合"摊开一张报纸"的开场。

### 纸片

- **撕纸卡** `tornCard`：撕开的边露出 0.3～0.6u 的白芯，下面一层软投影；剪报常用 `torn: 'tb'`（上下撕、左右剪）。
- **任意形状的剪纸** `piece`：云、浪、箭头都可以剪出来，带白边和投影。
- **剪报照片** `cutout`：白边 0.6u，剪刀剪的略歪的轮廓。
- **金句纸条** `strip`：一句话印在一条纸上。
- 每张纸片带 1～3° 的旋转，画面里至少叠两三层（底纸 → 卡片 → 胶带 / 图钉 / 批注）。
- **印章、马克笔、荧光笔都是"墨"**：和纸面相乘，没有投影；纸片才有投影。

### 照片素材

- **真实做片**：
  - 用用户上传的图片：`CL.cutout(w, { src: '/input/文件名', treatment: 'duotone' })`；
  - `treatment` 可选：
    - `duotone`：墨色双色调，默认；
    - `mono`：黑白；
    - `halftone`：网点印刷，网距 2u；
    - `none`：原图。
  - 同一支片统一用一种处理方式。
- **用户没给图片时**：
  - 用 `art` 占位插画（几何块加网点），可选 `storm`、`sea`、`city`、`portrait`、`phone`、`block`；
  - 或者用 `piece` 剪纸图形、`bars` 图表代替；
  - **不能用网上的图片**。
- **示例里的照片都是占位**：做片时换成用户的图，或者明确标"示意"。
- **地图**：
  - `mapScrap` 只画示意街区，不画国界和海岸线；
  - 需要真实地图时，用用户上传的合规地图（放进 `cutout` 的 `src`）。

### 印章、圈注、批注

- **印章** `stamp`：双线框或双圈，油墨不均匀，斜 6～12°。
  - 一镜最多一枚；
  - 盖在空白处或照片上，**不要压住正文**（slate-qa 会报重叠）。
- **马克笔**：
  - `circle` 圈注会转 1.1 圈，首尾错开；
  - 还有 `underline` 下划线、`arrow` 箭头、`strike` 划掉。
  - 圈注的框要把数字标签一起包进去。
- **手写批注** `note`：用 Long Cang 手写体，红色，从左往右"写"出来。每条不超过 10 个字。
- **荧光笔** `highlight`：要先于文字创建，才会刷在字的下面。
  - 暗场里不要用荧光笔，改用黄色纸条（`strip` 的 `tone: 'yellow'`）配黑字。
- **涂黑** `redact`：黑条盖住结论，到点揭起甩走；也可以从左往右涂黑。

### 色彩逻辑

- **纸**：几种中性纸色（白、米、新闻纸、牛皮），占画面的大部分。
- **墨**：深蓝黑 `CL.C.ink`。用于文字、线条、深色纸块（`tone: 'ink'`，比如海面、数据柱）。
- **强调色只有一个**：红 `CL.C.red`。只给印章、圈注、箭头、栏目标签、被点名的那组数据。
- **黄**：只做荧光笔，面积不超过画面的 5%。
- 不加新的色相。要区分多组数据，用"墨色纸 / 红色纸"和深浅，不用彩虹色。
- **字色跟着纸走**：
  - 卡片里的字自动用卡片的字色；
  - 直接印在底纸上的字，看底纸深浅；
  - 一般不用手动设颜色。

### 字体

| 用途 | 字体 | 来源与许可 |
|---|---|---|
| 正文、标签、数字单位 | Noto Sans CJK SC（思源黑体） | 系统字体，SIL OFL 1.1 |
| 标题、大数字、金句 | Noto Serif SC Black（思源宋体，900） | `/assets/fonts/NotoSerifSC-Black.woff2`，5.2 MB，SIL OFL 1.1（Google Fonts 发布版，未修改，许可全文见同目录 `NotoSerifSC-OFL.txt`） |
| 手写批注、图注 | Long Cang（龙藏体） | `/assets/fonts/LongCang-Regular.woff2`，2.9 MB，SIL OFL 1.1（同上，`LongCang-OFL.txt`） |

- **加载方式**：
  - `style.css` 已经写好 `@font-face`；
  - 组件用到哪种字体，就在渲染前等它加载完；
  - 没用到的字体不会下载。
  - 自己写 CSS 时，字体名写 `"Noto Serif SC"`（字重 900）或 `"Long Cang"`。
- **字号下限**：
  - 正文 3.6u；
  - 标签 2.8u；
  - 出处 2.1u；
  - 标题 6～7u。
- 屏上只放短文案（一行不超过 12 个字），完整的话交给旁白和字幕。

## 动画

- **风格三常量**：
  - **一拍二**：纸片、文字、柱子的动作用 `T = CL.step(t)`（30fps 下每 2 帧换一格，像定格动画）；镜头、颗粒、印章冲击用原始的 `t`，每帧都动。
  - **三档时长**：
    - 0.3 秒：标签、胶带、印章、图钉；
    - 0.5 秒：纸片落下或滑入；
    - 0.6～1.0 秒：圈注、箭头、标题印出、纸条揭起。
  - **统一入场**：纸片要么"落下"（`from: 'drop'`，从略高处落到纸面，投影收紧），要么从画外滑入（`left / right / top / bottom`）后落定。入场用 out 缓动。
- **永远不动的**：
  - 底纸只随镜头走；
  - 落定的纸片不漂浮、不呼吸；
  - 印章落定后不动；
  - 字不抖。
- **印章**：`stamp.set(t, at)`，0.09 秒从 2.6 倍砸到原大，落定那一帧抖一下。
  - 要配全画面冲击（轻震加白闪），就在 `stage({ punch: [at + 0.09] })` 里写上；
  - 全片最多 3 处，相邻至少隔 16 拍（约 8 秒）。
- **滑入途中的字**：在碰到安全区边缘之前就淡出，落定后才清楚，组件会自动处理。

## 节奏

- **每镜的长度**：6～10 秒，一镜讲一个点。
- **一镜里的元素**：
  - 3～6 个主要元素，每 1～2 秒落下一个新东西；
  - 全部落定后至少停 1.5 秒，让观众看清整页。
- **阅读时长**：屏上每段文字连续可见的时间 ≥ 汉字数 ÷ 4.5 + 1.5 秒。
  - 最后出现的文字要留够时间：比如 8 个字的纸条，至少在结束前 3.3 秒落定。
  - 计数器滚动中的数字不算。
- **对齐旁白**：
  - 圈注、印章、`bars.focus` 对准旁白点名的那个词（看 `SLATE.captions`）；
  - 数字落定后至少停 0.5 秒。
- **全片节奏**：快慢交替，数据剪报和"人话解读"的镜头交替出现。

## 镜头词汇表

镜头是标点：看得清就不动。快推、甩镜、砸入合计不超过镜头数的 1/3；不要连续三镜都往里推。

| 动作 | 怎么写 | 表达什么 | 适合内容 |
|---|---|---|---|
| 慢推 3～5% | 默认 `push: 0.04`，可加 `drift` | 引导注意力，让静止的版面"活着" | 任何镜头的底子 |
| 推向细节（≤8%） | `cam` 关键帧，后段推向某张卡片 | 强调：重点在这里 | 一张图看懂的最后一步、关键数字 |
| 横移 | `cam` 从左到右，配 `st.guard` | 逐步揭示、时间推进 | 时间线、证据墙、长剪报 |
| 拉远 | `cam` 从 1.06 拉到 1.0 | 揭晓全貌 | 收尾总结、"其实它们是一回事" |
| 视差 | 内容分放 `st.back` / `st.world` / `st.front` | 纸片之间的纵深 | 前景胶带、图钉、批注 |
| 砸入 | 印章加 `punch` | 定性、下结论 | 辟谣、预警、结论（全片 ≤3 次） |

## 转场

- **主转场：网点**
  - 写法：上一镜 `exit: 'dots'`，网点在最后 0.24 秒盖满画面；下一镜 `enter: 'dots'`，网点在开头 0.24 秒退去。
  - 两镜的推进方向一致，切点正好在盖满的那一帧。
  - 一镜之内要切换两组内容时，用 `st.wipe(t, at)`，它返回 true 时换成第二组。
- **备用转场：新纸盖过来**
  - 写法：上一镜 `exit: 'sheet'`。
  - 要求：下一镜底纸的 `paper`、`seed` 相同，并且 `t = 0` 时镜头不推不移（`cam` 第一帧是 `[0, W/2, H/2, 1]`）；下一镜从空白纸面开始落东西。
- **硬切**：同一张纸上换内容，新内容一拍二落下。
- **不用**：
  - 淡入淡出、溶解（最后手段）；
  - 翻转、模糊、缩放转场。
- **转场就是退场**：除最后一镜外，不做单独的退场动画。

## 三种结构

1. **冷开场 → 回溯 → 递进 → 反转 → 回到开场**：用一条具体的新闻或一个反常识的事实开场，接着讲"要理解它，得回到……"，递进部分占一半以上，最后用新知识重新解读开场那张剪报。
2. **证据墙**：一个问题，几条线索依次钉上墙（卡片 + 图钉），最后用红线连起来，得出结论。
3. **一张图看懂**：先给全图的骨架，再按 ①②③ 逐块贴出并推近讲解，最后拉远回到全图。

## 三种开场

1. **剪报砸下来**：一张剪报落下，盖章，圈出关键词，抛出问题纸条。
2. **一个数字或日期**：撕页日历翻到某天，或者一个大数字滚动停住，再盖一枚章。
3. **一句涂黑的话**：黑条盖着一句话，揭开后露出问题。

## 三种结尾

1. **金句纸条加回扣**：结论纸条依次贴上，开场那张剪报或照片重新出现。
2. **印章落版**：所有内容落定后，盖一枚结论章（配一次 `punch`），慢推停住。
3. **拉远看整面墙**：镜头拉远，所有卡片组成一面证据墙，红线连起来。

示例只演示语法：做片时不要照搬示例的故事、文案和时长。

- 只用用户给的或有出处的数字，每个数据画面都用 `CL.sourceTag` 标来源和日期（放 `st.hud`）。

  - "示例新闻""示例数据"角标要去掉。
- 措辞要克制：用"约""原因之一"，不说"唯一""最"。

## 用法

```html
<link rel="stylesheet" href="/skills/collage/style.css">
<script src="/skills/collage/components.js"></script>
<script>
  const { seg, u: U, width: W, height: H } = SLATE;
  const st = CL.stage({ paper: 'cream', push: 0.04, exit: 'dots' });
  const h = CL.heading(st.world, { kicker: '一张图看懂', text: '标题不超过 12 个字' });
  const box = st.area({ top: h.bottom + U * 2 });   // 标题下沿到字幕区之间，推近后仍在安全区里
  const card = CL.tornCard(st.world, { x: box.x, y: box.y, w: box.w * 0.55, h: box.h, tone: 'newsprint', rotate: -1.5 });
  const line = CL.text(card.inner, { x: card.x + U * 4, y: card.y + U * 10, text: '卡片上的字放进 card.inner', size: U * 3.6 });
  const ring = CL.circle(card.inner, { x: card.x + U * 3, y: card.y + U * 6, w: U * 30, h: U * 5 });
  const src = CL.sourceTag(st.hud, { text: '来源：…… · 2026-09' });
  function render(t) {
    const T = CL.step(t);      // 一拍二
    st.set(t);                 // 第一行：镜头、底纸、颗粒、转场
    h.draw(seg(T, 0.2, 1.2));
    card.draw(seg(T, 0.6, 1.1));
    line.draw(seg(T, 1.0, 1.4));
    ring.draw(seg(T, 2.0, 2.6));
    src.draw(seg(T, 1.2, 1.6));
  }
</script>
```

- **图层**：
  - 内容放 `st.world`，跟着镜头走；
  - 出处、角标、横移镜头里的标题和日历放 `st.hud`，固定在屏幕上。
- **排版**：
  - 用 `st.area()` 算内容区；
  - 主体居中、左右均衡，主图占画面高度的 30%～50%；
  - 文字不进 `SLATE.captionZone`。
- **竖屏（9:16）**：组件都按 u 排版，可以直接用。示例是横屏版式，竖屏时改成上下排列（标题 → 主图 → 纸条），主体放在画面高度的 20%～60%。
- **组件参数**：写在 `components.js` 每个函数前的注释里。
- **全局变量名**：不要用 `top`、`name`、`parent`，它们和浏览器自带的全局变量冲突。
- **render 里不新建元素**：所有元素在脚本开头一次性建好，`render(t)` 里只调用 `draw` 和 `set`。
- **量文字宽度**：用 `CL.textWidth(el)`。直接调用 `getComputedTextLength` 会受镜头缩放影响，同一帧的结果可能不一致。

## 常见问题（症状 → 修法）

| 症状 | 修法 |
|---|---|
| 像幻灯片：卡片方正、平铺、同时出现 | 给纸片 1～3° 旋转，叠两三层；入场用 `T = CL.step(t)` 错开落下 |
| 颜色花 | 只留红一个强调色，其余用纸色和墨色 |
| slate-qa 报 `overlap`：印章或标签压字 | 印章挪到空白处或照片上；旋转过的卡片文字框会变大，标签和标题之间留 1.5u 以上 |
| slate-qa 报 `outside_safe` | 推近的镜头用 `st.area()` 排版；横移镜头把标题放 `st.hud`，世界里的文字用 `st.guard` |
| 网点糊成一片灰或出摩尔纹 | 网距不小于 2u（组件已经限制） |
| 圈注切到数字 | `circle` 的框要包住数值标签，从最高的标签算起 |
| 两镜接缝处纸纹跳了一下 | 用 `sheet` 转场时，两镜的 `paper`、`seed` 要相同，下一镜 `t = 0` 时镜头不推不移 |
