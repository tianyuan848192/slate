# 数据叙事

## 画面

- **数据规则（最重要）**：
  - 数据只用用户给的数字（表格、文档、口述），或者联网查到、有出处的数字。不要编数字，也不要为了好看去"凑整"或换算出新的数；
  - 每一镜只要用到数据，画面角落就要有出处脚注（`DS.source`）。用户给的数据写"来源：用户提供的……"，查到的数据写机构和年份，并把来源写进 `sources.json`；
  - 一张图只突出一个对比（`focus` 加 `DS.compare`），其余的数据作为背景。
- 底色 `#13294B`（深蓝），柱子和线用蓝色 `#4F86E0`。
- 高亮只用琥珀 `#F4B400`：被突出的那根柱子、那个点、对比标注、大数字卡的竖条。
- 文字分三级：白色 `#FFFFFF`（数值、标题）、浅蓝 `#AFC0DD`（类目、标签）、灰蓝 `#7F93B8`（刻度、出处）。文字不用系列色。
- 多个系列（比如环形图）按 `DS.C.series` 的固定顺序取色，并且一定要有图例或直接标注。
- 网格线和坐标轴要细、要淡，不要抢数据的风头。柱子从同一条基线往上长，顶部是小圆角。数值标在柱顶或线的终点，不要每个点都标。
- 版式：
  - 标题（`.ds-title`）和单位、口径说明（`.ds-sub`）放在左上角；
  - 图表放在左侧或中间，大数字卡（`DS.stat`）放在右侧；
  - 出处在右下角，组件会自动放在字幕区以上。
- 一镜只放一张图和一个大数字。不要用 3D 图表，不要画双纵轴。

## 动画

- 图表跟着旁白一步步长出来：先出坐标轴，再按旁白提到的顺序长柱子、画线、扫环形。每一项 0.4～0.6 秒，用 `SLATE.captions` 对齐提到它的时刻。
- 讲到结论时再高亮：`focus(i, p)` 让主角变成琥珀色，其余降到 35%，然后画出对比标注 `DS.compare`。
- 关键数字最后出场：在 `DS.stat` 里滚动到目标值并轻微放大，**至少停留 2 秒**。
- 转场：下一镜从空坐标轴开始重新长。不做翻转、飞入这类花哨动画。

## 节奏

- 每镜 7～12 秒：前 1/3 让图表长出来，中间高亮对比，最后 1/3 留给大数字停留。
- 一句旁白只讲一个数字。数字在旁白里出现的同一时刻，画面上也要出现。

## 用法

```html
<link rel="stylesheet" href="/skills/datastory/style.css">
<script src="/skills/datastory/components.js"></script>
```

- 页面主体放一个铺满的 `<svg class="ds-canvas">`。先在脚本里用 `DS.*` 创建组件，再在 `render(t)` 里调用它们的 `draw(p)` 和 `focus(i, p)`，`p` 是 0～1 的进度。
- 图表的 `x, y, w, h` 是绘图区：刻度文字画在它左边，类目文字画在它下方，柱顶数值画在它上方，排版时要留出这些位置。
- 组件列表：
  - `DS.bars`：柱状图（一个系列）。`draw(p)` 画整张图，`bar(i, p)` 单独长第 i 根，`top(i)` 返回柱顶上方的点（给 `DS.compare` 用）；
  - `DS.line`：折线图。线按进度画出来，下面带一层淡淡的面积；`focus(i, p)` 圈出一个点并标出数值；
  - `DS.donut`：环形图。中间可以放一个数字，`legend` 指定图例的位置，图例里每项都带百分比；
  - `DS.stat`：大数字卡，包括标签、滚动的数字、单位和变化标签（`delta`）；
  - `DS.compare`：对比高亮，两点之间的折线箭头加琥珀色标注；
  - `DS.source`：出处脚注，`corner` 可选 `br`（默认）、`bl`、`tr`、`tl`。
- 参数和完整示例见 `components.js` 文件头注释和 `example/index.html`。
