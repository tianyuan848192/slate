# 编辑图解

像杂志和技术文档里的插图：一张纸、几根细线、一处强调色，把一个道理讲清楚。默认用它做"讲明白一件事"的片子：技术原理、工艺流程、商业分析、知识科普。

## 是什么 / 不是什么

**是什么**（一眼可辨的五个特征）：
1. 暖灰纸底（带极淡的纸纹），墨色发丝线，**全片只有一种强调色**；
2. 标题是宋体，左上角一小截强调色短条 + 栏目小字，下面一条通栏发丝线；
3. 图先以 14% 的浓度整体出现（铅笔稿），旁白讲到哪里，哪里就"上墨"；
4. 当前讲的那一项用强调色，讲过的压到约 55%，没讲到的还是铅笔稿；
5. 每个数据画面左下角有一行出处小字。

**不是什么**：
- 不是 PPT：不用项目符号堆字、不用渐变底、不用阴影和发光、不用图标墙；
- 不是白板手绘：线条是规整的发丝线，不抖、不手写；
- 不是发布会大字：一屏讲一个关系，而不是喊一句口号；
- 不是霓虹数据秀：数据图克制，颜色只给要你记住的那一个数。

## 画面

### 色彩逻辑
- **一种强调色，只给"现在讲的"和"要你记住的"**：当前步骤、转折点、关键柱子、结论数字、注释引线。一屏里强调色的面积不超过约 5%。
- 其余全部用墨色灰阶：墨（主文字、主线条）、墨二（说明文字、图标）、灰（刻度、出处）、标记灰（非重点的柱子和线）、发丝线和网格。
- 文字永远用墨色，不用系列色；颜色只放在标记（柱、线、点、边框）上。
- 默认强调色是朱红 `#B83D1B`。品牌片可以用 `ED.stage({ accent })` 换成品牌色，换之前确认它在纸色上的对比度 ≥ 4.5:1（参考：钴蓝 `#2B59C3`、青绿 `#13766B`、紫 `#7A4A9A` 都合格）。
- 必须区分 3 个以上对象时才用 `ED.C.series`（朱红、钴蓝、绿、紫、赭黄，按顺序分配，跟着对象走，不按名次）。这组颜色在亮、暗两种纸色上都校验过色觉障碍可分辨。超过 5 个对象就合并成"其他"或拆成几张图。
- 暗色版 `theme: 'dark'`：墨蓝灰纸、米白字、亮一档的朱红。适合夜间、科技题材，整片统一用一种。

### 纸张和线条
- 纸：`#F0EDE7`，纸纹在加载时用固定种子烘焙一次，不随时间变化。架构图、关系图可以加 `grid: 'dots'`（4u 点阵）。
- 线宽（都已写在组件里）：网格 0.15u、发丝线 0.16u、连线 0.2u、强调 0.32u、数据线 0.42u。视频里线不能比 0.15u 更细，压缩后会断。
- 连线只走横竖两个方向，拐弯处是小圆角；先描线，箭头最后出现。
- 节点有 7 种处理：`box` 实框（默认）、`solid` 墨色实底（输出、结论）、`store` 顶部双线（存储）、`external` 虚线框（外部系统、用户）、`optional` 点线框（可选）、`accent` 强调色浅底（全片主角）、`plain` 无框。

### 字号层级（u = 短边的 1%）
| 层级 | 字体 | 字号 | 用在 |
|---|---|---|---|
| 大数字 | 宋体 | 14～24u | `ED.number`、占比环中心 |
| 术语 | 宋体 | 9u | 定义卡 |
| 标题 | 宋体 | 6.4u | `ED.heading` |
| 表头、年份 | 宋体 | 4.2～4.8u | 对比表头、时间线年份 |
| 正文、节点名 | 黑体粗 | 3.3～4.4u | 节点标题、对比数值、总结要点 |
| 说明 | 黑体 | 2.5～2.9u | 节点副标题、注释补充 |
| 栏目、刻度、出处 | 黑体 | 1.9～2.3u | kicker、坐标轴、`ED.source` |

### 字体
- 宋体：**Noto Serif SC SemiBold（思源宋体）**，SIL Open Font License 1.1，文件 `/assets/fonts/NotoSerifSC-SemiBold.woff2`（约 5.8 MB，与其他风格共用），许可全文在同目录的 `NotoSerifSC-OFL.txt`。`style.css` 已经写好 `@font-face`，`ED.stage()` 会在渲染前预加载。
- 黑体：Noto Sans CJK SC（SIL OFL 1.1，镜像自带）。
- 宋体只给"说话的人"：标题、术语、大数字、年份、表头。正文、标签、数值一律黑体。

## 动画

- **三常量**：
  - 签名缓动 `ED.ease.enter`（四次方减速，入场）、`exit`（出场）、`move`（画面内移动、描线）；
  - 三档时长 `ED.D`：快 0.35 秒（强调切换）、中 0.6 秒（上墨、描线）、慢 1.0 秒（行展开、图表生长）；
  - 统一入场：从幽灵态（或透明）上墨，同时上移 0.7u。标题用遮罩上升。
- 同一时刻最多两样东西在出现；一组错峰的总时长不超过 0.5 秒。
- 强调色跟着旁白走：`flow.set`、`graph.set` 的时间点、`compare.focus`、`timeline.focus` 都对齐 `SLATE.captions` 里点名的时刻。
- 末帧必须是完整的静态图并停住至少 1 秒；用 `release` 让讲过的步骤恢复浓度。
- **永远不动的**：纸、标题、出处、坐标轴。没有呼吸、漂浮、闪烁、弹跳、发光。
- 镜内换页用 `ED.swap`（强调色发丝线从左扫到右）；镜与镜之间硬切——每镜的标题和规线在同一位置，切过去像翻到下一页。

## 节奏

- 每镜 6～10 秒，一镜讲一个关系（一条流程、一组对比、一段时间线或一张图）。
- 屏上文字连续可见 ≥ 汉字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 秒（不少于 1.5 秒）。所以最后出现的文字要在结束前留够时间；想加快就少放字，不要提前切。
- 前 1 秒内要有东西：标题 + 幽灵态的整张图。
- 每 2～4 秒要有新事件（新的一步上墨、一条注释、一次强调切换）；超过 1 秒的全静止只留给结尾。
- 关键数字在旁白念到时落定，之后至少停 0.5 秒。

## 镜头词汇表

镜头是标点：看得清就不动。默认 `ED.stage()` 不动。

| 动作 | 怎么写 | 表达什么 | 适合内容 |
|---|---|---|---|
| 静止 | 默认 | 让观众读图 | 绝大多数镜头 |
| 缓推 | `push: [1, 1.025]` | 收拢注意力 | 结论镜、定义卡 |
| 横移 | `camera` 关键帧移动 x | 逐步揭示 | 很长的时间线、很宽的架构图 |
| 推近一处 | `camera` 关键帧 z 到 1.3～1.6 | 强调细节 | 架构图里某一个模块 |
| 拉远揭晓 | `camera` 从 z>1 回到 1 | 看全貌 | 讲完局部后回到整张图 |

快推、甩镜、震屏不用。用了镜头运动时，标题和出处放 `st.hud`（不跟镜头动），内容离安全区边缘留 3u 以上。

## 三种结构

1. **问题 → 机制 → 结论**：开场一个具体问题（定义卡或大数字）→ 两三镜流程或架构讲机制 → 总结卡。最常用。
2. **对比展开**：开场一组反差（对比双栏）→ 逐项拆开讲差别从哪来（流程或数据图）→ 回到对比给选择建议。
3. **时间线推进**：开场时间线全貌 → 挑两三个转折点各讲一镜 → 结尾回到时间线，强调落在"今天"。

## 三种开场

1. **定义卡**：一个术语、一句定义（`ED.define`），适合"什么是 X"。
2. **铅笔稿全貌**：标题 + 整张图的幽灵态，第一句旁白就开始上墨（`flow.draw` / `graph.draw` / `timeline.prime`）。
3. **一个数字**：居中的宋体大数字（`ED.number`，`anchor: 'middle'`），下面一行说明它是什么。

## 三种结尾

1. **总结卡**：`ED.recap` 编号要点，2～4 条，最后一条可以 `focus`。
2. **回到全图**：把前面讲过的流程或架构完整重现，`release` 后整张图恢复浓度，强调色只留在结论上。
3. **一句话 + 一个数**：居中标题加一个大数字，像杂志的结尾页。

## 横屏和竖屏怎么排

组件按 `SLATE.width/height` 自动判断画幅。先用 `ED.area(h)` 取内容区，再按比例分配，不要写死像素。

- **横屏 16:9**：
  - 标题在版心左上；内容区是标题规线到出处行之间（约画面高度的 22%～76%）。
  - 流程默认横排，时间线横向、标签上下交替，对比双栏左右各一半；图表在左 60%、关键数字在右的"图 + 数"组合很好用。
- **竖屏 9:16**（按 1080×1920 设计，字号和横屏一样按短边算）：
  - 顶部 7.5% 留给平台顶栏，标题从这里开始；字幕区从 70% 高度开始，下面是平台按钮，内容都放在 7.5%～67% 之间，组件会自动处理。
  - `ED.flow` 自动竖排，`ED.timeline` 自动竖向（年份在轴左、事件在轴右）。
  - 对比双栏照样左右排，但数值要短（每格不超过 7 个字）。
  - 标题超宽时自动在"，""："处断行。
  - 节点宽度用内容区的比例（例如流程占左边 52%，旁支节点放右边 34%）。
  - 竖屏的知识卡片：从上到下"定义卡 → 图 → 数字"三段，左边对齐同一条线。

## 用法

```html
<link rel="stylesheet" href="/skills/editorial/style.css">
<script src="/skills/editorial/components.js"></script>
<script>
  const { seg, u: U } = SLATE;
  const st = ED.stage();                                   // 必须最先调用；暗色版 ED.stage({ theme: 'dark' })
  const h = ED.heading(st.world, { kicker: '原理 · 检索增强生成', text: 'RAG：先查资料，再作答', mark: '再作答' });
  const A = ED.area(h);                                    // {x, y, w, h, cx, cy, portrait}
  const f = ED.flow(st.world, { ...A, steps: [{ title: '提问', icon: 'user' }, { title: '检索', icon: 'search' }, { title: '生成', kind: 'solid' }] });
  const src = ED.source(st.hud, { text: '来源：…… · 2026-09' });
  function render(t) {
    st.set(t);
    h.draw(seg(t, 0, 0.9));
    f.draw(seg(t, 0.3, 1.0));                              // 幽灵态铺底
    f.set(t, [1.0, 2.2, 3.4], { release: 4.8 });           // 每一步点亮的秒数，对齐旁白
    src.draw(seg(t, 1, 1.5));
  }
</script>
```

- 组件在创建时一次性生成元素；`render(t)` 里每帧都要调用它们的 `draw / set / focus`（不调用就保持上一次的值）。
- 参数写在 `components.js` 每个函数前的注释里。
- `ED.stage` 每帧会让整层重新光栅化（滤镜在视觉上是恒等的），保证分段渲染和顺序渲染逐像素一致，不要关。
- **不要用 `top`、`name`、`parent` 当全局变量名**，和浏览器自带的全局变量冲突，脚本会报错。

### 组件清单

| 类别 | 组件 | 用途 |
|---|---|---|
| 版面 | `stage` | 纸面、内容层 `world`、贴屏层 `hud`、镜头 |
| | `frame`、`area` | 版心和内容区（已避开字幕区和竖屏平台区） |
| | `heading` | 强调色短条 + 栏目 + 宋体标题 + 通栏规线 |
| | `text`、`tag`、`source`、`legend`、`icon` | 旁注、角标（"示例数据"）、出处、图例、31 个线条图标（`ED.ICONS`） |
| | `layer`、`swap` | 图层；镜内换页（强调色发丝线扫过） |
| 图解 | `node`、`link`、`zone` | 节点（7 种处理）、正交连线（可带标签、虚线、流动圆点）、分区框 |
| | `flow` | 流程：节点 + 连线，按时间依次点亮 |
| | `graph` | 关系图、架构图：任意拓扑，比例坐标，按计划逐步上墨 |
| | `compare` | 左右对比、前后对比（`arrow: true`），主角栏垫卡片 |
| | `timeline` | 时间线：真实间隔，横竖自适应，太挤自动错开 |
| | `callout`、`bracket` | 注释引线、差值括号 |
| 数据 | `bars` | 柱状图（竖排或横排），灰柱 + 一根强调 |
| | `line` | 折线图：笔头实时数值、末端标签、两线之间铺"差距"带 |
| | `ring` | 占比环：一个占比或几部分 |
| | `number` | 宋体大数字，滚动后停住 |
| 卡片 | `define` | 概念定义卡：术语、外文名、定义、要点 |
| | `recap` | 收尾总结卡：编号要点 |

## 数据可信度

- 只用用户给的或有出处的数字；每个数据画面都要有 `ED.source`，写明来源和日期。来源写进 `sources.json`。
- 自己算的数（比如复利）写明算法和假设；占位数字要标"示例数据"（`ED.tag`），正式做片时换掉。
- 轴从 0 开始；时间按真实间隔；比例条按真实比例画（比如水温条按 0～100°C）。量级差太大画不出来时，只写文字，不画条。

## 坑（症状 → 修法）

- 节点里的字换成三行、溢出框外 → 加宽节点或删字；窄节点用 `align: 'center'`（图标放到标题上方）。组件最多把字缩到 85%。
- 连线标签压住节点边框 → 两个节点离得太近；拉开距离，或用 `labelDx / labelDy` 把字挪到线外，或删掉标签。
- 注释文字和曲线、柱子打架 → 把注释放进图里的留白处（曲线上方、柱子之间），引线默认先竖后横。
- 最后出现的字一闪就切了 → 按阅读时长公式倒推出现时间，或删字。
- 一屏里两处强调色 → 只留旁白正在说的那一处，其余 `focus(0)`。
- 画面一半是空的 → 用 `ED.area` 的比例分配，让主要图形占内容区的 60% 以上；竖屏把图放大，别缩在顶部。
