# 发布会大字

## 画面

- 底色 `#0E1220`（深夜蓝，中间略亮），大字用白色 `#FFFFFF`，副标题用灰色 `#8A93AA`。
- 强调色只用一种：`#F4B400`（琥珀）。每屏最多一处，比如句子里的关键词、数字后面的单位或一条强调条。
- 字体用 `"Noto Sans CJK SC"` 最粗的 900，字距收紧。
- **一屏一句话**，大字不超过 8 个字。可以配一行副标题，副标题的字号不到大字的 1/6。
- **关键数字单独占一屏**，字号至少是画面高度的 30%（`KN.number` 默认 34%）。上面可以放一行小标签，说明这个数字是什么；下面放一行灰色脚注，写对比条件或出处。
- 版式：
  - 句子屏左对齐，起点在画面左侧约 10% 处，整块文字在画面中部偏上；
  - 数字屏居中；
  - 产品屏左字右图。
- 留大块空白，不要堆图标、花纹或多余装饰。所有内容都在字幕区以上。

## 动画

- 每屏开头 0.5 秒内完成入场，只用两种方式：
  - 逐字升起：`mode: 'rise'`，每个字间隔 0.06～0.08 秒；
  - 遮罩擦出：`mode: 'wipe'`，琥珀色竖条带着文字从左往右露出来。
- 数字用 `KN.number` 逐位滚动，1～1.2 秒内停住，停住后不再变化。
- 强调条（`KN.bar`）和副标题（`KN.sub`）比大字晚 0.4～0.7 秒出现。
- 整屏在停留期间缓慢推近 1.5%～3%（`KN.screen` 的 `push`）。
- 屏与屏之间**硬切**，不淡入淡出，不做转场动画。

## 节奏

- 每屏 1.5～3 秒，数字屏至少停留 1.5 秒。旁白一句对应一屏。
- 切点对齐配乐的节拍，用 `KN.beats(n, bpm)` 算出第 n 拍的秒数：
  - `tech` 配乐是 120 BPM，一拍 0.5 秒（默认）；
  - `bright` 配乐是 108 BPM，一拍约 0.556 秒。
- 这一镜的时长也尽量取整数拍，这样后面几镜的切点也能对上节拍。

## 用法

```html
<link rel="stylesheet" href="/skills/keynote/style.css">
<script src="/skills/keynote/components.js"></script>
```

- 页面主体放一个铺满的 `<div id="stage">`。
  1. 每一屏用 `KN.screen(stage)` 建一个图层，再往这一屏里放组件；
  2. 用 `KN.cuts(屏数组, 每屏开始的秒数)` 编排硬切；
  3. `render(t)` 里先调用 `cut.set(t)`，再把 `cut.local(t, i)`（第 i 屏的屏内秒数）传给这一屏各个组件的 `set(lt)`。
- 位置和字号都是像素，按 `SLATE.u`、`SLATE.width`、`SLATE.height` 的比例算。`delay` 是组件在屏内晚多少秒出现。
- 组件列表：
  - `KN.screen`：一屏，`push` 是缓慢推近的幅度；
  - `KN.cuts`：按节拍硬切，只显示当前这一屏；
  - `KN.beats`：第 n 拍对应的秒数；
  - `KN.headline`：大字一行，逐字升起或遮罩擦出，`accent` 指定要用强调色的那几个字；
  - `KN.number`：数字滚动，支持 `prefix`、`suffix`、小数位 `digits`，`accent` 指定哪一部分用强调色；
  - `KN.sub`：副标题；
  - `KN.bar`：强调条；
  - `KN.card`：产品占位卡，有产品图时传 `src: '/input/文件名'`，没有时显示占位线稿。
- 参数和完整示例见 `components.js` 文件头注释和 `example/index.html`。
