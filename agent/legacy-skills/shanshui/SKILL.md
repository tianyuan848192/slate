# 水墨山水

一张宣纸，几层远山，一缕云雾，一列竖排题字，最后落一方红印。画面大面积留白，每镜只做一件事，节奏慢而稳。

## 是什么 / 不是什么

- **是**：
  - 宣纸或绢底；
  - 远山由淡到浓层层叠起，层与层之间隔着云雾；
  - 竖排书法题字，配小字题款和朱砂印；
  - 留白占画面 60%～80%；
  - 镜头锁定，或者像展开手卷一样极慢地横移。
- **不是**：
  - 国潮平涂：锁定四色、粗墨线、祥云回纹，那是另一种风格；
  - 窗花剪纸、工笔重彩、敦煌壁画；
  - 霓虹、光晕、粒子、渐变底、震屏、闪白、快切。
  - 不画具体人物的面孔，人物只用剪影或背影（比如船上的蓑笠人）。

## 适合的题材

| 类型 | 例子 |
|---|---|
| 品牌广告 | 茶（明前春茶、白茶、岩茶）、酒（黄酒、年份礼盒）、瓷器、香道、文房 |
| 文旅 | 山水目的地（江、峰、湖）、古镇、景区节庆 |
| 讲解 | 二十四节气、古诗词赏析、书法和茶道等传统文化、企业文化片里的"东方"段落 |

## 画面

### 纸

- `SS.stage({ paper: 'xuan' })` 是宣纸：纤维、云状深浅、杂点和暗角都在创建时画好。
- `paper: 'silk'` 是绢：更暖，带极细的经纬，适合诗词和收尾。
- 纸是底，什么都不画的地方就是留白。不要再往纸上铺渐变或色块。

### 墨色浓淡（墨分五色）

- 远山最淡，近山最浓，大约是焦、浓、重、淡、清五档，`SS.mountains` 会按层数自动分配。
- 每层山的山脊有一道深墨（潮线），粗细和浓淡随笔意起伏；往下顺坡皴擦，再慢慢化进雾里。
- 山越高墨越浓，山谷淡。近山会挡住远山（有纸色遮挡），不会透出后面的山脊。
- 点苔和远树只点在近处几层的高处，作为画面里最深的墨点。

### 留白

- 一屏里有墨的地方不超过 40%。文字放在留白处，不要压在深色山体上。
- 山一般只占画面下半部；上半部留给天空、月亮、飞鸟和题字。
- 构图要有疏密：主峰（`peak`）和题字分放两侧，中间留空。

### 远山层叠和云雾

- 一般 3～5 层（`layers`），层与层之间自动加一道云雾（`mist: true`）。层数越多越慢，也越容易发灰。
- 三种山形：`range` 连绵山脉（尖峰），`karst` 喀斯特孤峰（适合桂林、漓江这类江景），`hills` 缓丘（茶山、田园）。
- 云雾是纸色的，只改变浓淡、缓慢漂移，不翻滚，不改变形状。
- 有江湖的画面用 `SS.water`：水线以下铺回纸色，近山倒影逐行错开做波纹，再加几笔水纹。

### 竖排题字、题款、印章

- **题字**（`SS.vtitle`）用毛笔楷书，2～6 字，字号 9～12u。竖排从上往下，去掉标点。
- **诗句**（`SS.verse`）从右列起读，每列一句。
- **题款**（`SS.inscription`）是宋体小字，放在题字左侧，比题字低一两个字的位置起笔。
- **印章**（`SS.seal`）压在题款末尾下方：
  - `bai` 是白文，红底白字；`zhu` 是朱文，红字红边。
  - 一镜最多一方印，全片两三方。
  - 印文 1、2、4 个字最好。品牌片用品牌名，诗词片用一个意象词。

### 色彩逻辑

- 一镜只用一套调板，整片保持一致：
  - `shuimo` 水墨：纯墨，远山带一点花青冷调。适合诗词、节气、文旅。
  - `qinglv` 青绿：山脊用墨，山体上石青（远）到石绿（近）。适合茶、春夏、青山绿水。
  - `zhujin` 朱金：暖纸、赭石山体。金色只给日轮（`SS.moon({ kind: 'sun' })`）和一处点睛。适合酒、年节礼盒、秋冬。
- **朱砂只给印章**，全片唯一的红，面积不超过画面约 3%。不要用红色写字、画花或做按钮。
- 文字永远是墨色（`SS.C.ink`、`ink2`、`muted`）。压在浓墨横扫上的字用纸色（`SS.C.paper`）。
- 彩色只上在山体上，不上在文字、线条和印章以外的地方。

## 字体与文字

| 用途 | 字体 | 许可 | 文件 |
|---|---|---|---|
| 题字、诗句 | 马善政毛笔楷书 Ma Shan Zheng | SIL OFL 1.1 | `/assets/fonts/MaShanZheng-Regular.woff2`（3.1 MB） |
| 标题、题款、题签、印文 | 思源宋体 Noto Serif SC SemiBold（600） | SIL OFL 1.1 | `/assets/fonts/NotoSerifSC-SemiBold.woff2`（5.5 MB） |
| 兜底 | Noto Sans CJK SC | SIL OFL 1.1 | 系统字体 |

- 两款字体都来自 Google Fonts 官方发布，许可证全文在 `/assets/fonts/MaShanZheng-OFL.txt` 和 `/assets/fonts/NotoSerifSC-OFL.txt`。
- `style.css` 已经用 `@font-face { src: url(/assets/fonts/…woff2) }` 声明好，`components.js` 会在渲染前加载完。场景里不用再写 `@font-face`。
- 字号下限：
  - 正文、题款、题签不小于 3.6u；
  - 标题 5～7u；
  - 题字 9～12u。
- 屏上的字不等于旁白：一处文字不超过 8 个字。旁白念白话，画面上放原文或关键词。
- 画面里有诗句时，旁白念白话解读，不要和字幕重复同一句。
- 字幕的样式在 style.css 里已经设好（浅纸色底、墨色宋体），不要自己写字幕。

## 动画

### 风格三常量

- **签名缓动**：
  - 入场用 `ease.out`（墨落纸上，先快后慢）；
  - 镜头和转场用 `ease.inOut`；
  - 写字的进度用 `ease.linear`，组件内部每个字自带缓动。
- **三档时长**：
  - 钤印 0.3～0.4 秒；
  - 单字或单个元素晕开 0.6～1.2 秒；
  - 墨晕转场 1～1.5 秒。
- **统一入场**：所有东西都是"墨晕开"，也就是从中心向外显出、边缘带一圈淡墨，不做飞入、弹跳和翻转。
- 回弹只给印章（从 1.5 倍压到 1 倍）。

### 招牌动作

| 动作 | 组件 | 用在哪里 |
|---|---|---|
| 墨晕扩散 | `stage({ enter: 'bloom' })`、`SS.inkBloom` | 开场显影：画面从白纸里的一滴墨晕开；也可以在镜内换景 |
| 墨盖满 / 墨退去 | `exit: 'ink'` 接下一镜 `enter: 'wash'` | 两镜之间的签名转场，切点落在满屏墨色那一帧 |
| 笔触生长 | `SS.stroke`、`SS.inkSweep`、`SS.plum` | 起笔略顿、收锋变细，笔尾出现飞白；梅枝按枝干、小枝、开花的顺序长出 |
| 逐字题写 | `SS.vtitle`、`SS.verse`、`SS.heading` | 每字从字心晕开；诗句每字 0.42 秒，换列多停 0.3 秒 |
| 云雾流动 | `SS.mountains`（自动）、`SS.mist` | 环境动作：缓慢漂移，浓淡呼吸 |
| 手卷横移 | `stage({ pan: [起, 止] })` | 镜头从右往左展开（pan 从正到负），远山慢、近山快 |
| 钤印 | `SS.seal` | 一镜最后一个动作，落定后至少停 1.5 秒 |
| 孤舟、飞鸟、月出 | `SS.boat`、`SS.birds`、`SS.moon` | 环境动作，能量不超过主动作的 20% |

### 什么永远不动

- 纸。
- 已经写好的字，不晃、不呼吸。
- 落定的印章。
- 标题和题款跟着 hud 层，不随镜头移动。

## 节奏

- 每镜 6～10 秒：一个主动作（题字、长枝、展卷三选一），加 1～2 个环境动作（云雾、飞鸟、涟漪）。
- 主动作的顺序是"景先出，字后写，印最后"。不要同时出两组字。
- **阅读时长**：屏上一处文字连续可见的时间不少于"汉字数 ÷ 4.5 + 1.5 秒"，标题不少于 4 秒。
  - 想加快就少放字，不要提前把字撤掉。
  - 例：6 个字要停 2.9 秒以上。
- 全片快慢交替：讲解段可以 6 秒一镜，开场和收尾放慢到 8～10 秒。
- 本风格不用全画面冲击（震屏、闪白、缩放泵）。需要重音时，用钤印或一笔浓墨横扫代替。

## 镜头词汇表

| 动作 | 表达什么 | 适合内容 |
|---|---|---|
| 锁定不动（默认） | 静观、留白、读字 | 题字、诗句、三候这类需要读的画面 |
| 极慢推近（`zoom: [1, 1.03～1.05]`） | 沉浸、走进画里 | 诗词意境、品牌题字 |
| 手卷横移（`pan`，整镜 50～100u） | 逐处展开、一路看过去 | 文旅地名、流程、时间线 |
| 缓缓抬升（`lift`） | 从山脚望到山顶，或从水面望到天空 | 登高、日出、月出 |
| 景深视差（远山 depth 0.2，近山 1） | 空间感 | 所有带镜头运动的山水画面 |
| 镜内墨晕换景（`SS.inkBloom`） | 时间流逝、换一个地方 | 节气更替、"十年后" |

- 不要连续三镜都推近；一镜里只用一种镜头运动。
- 推近不超过 1.06 倍：再大的话纸纹会被放大，画面就假了。

## 转场

- **签名转场**：墨盖满接墨退去（`exit: 'ink'` 接下一镜 `enter: 'wash'`），全片 60%～70% 的切换用它。
- **点缀**：
  - 墨晕显影（`enter: 'bloom'`），用于片头或段落开头；
  - 留白淡出（`exit: 'fade'`，或者自己把景物淡掉），用于片尾。
- 转场就是退场：除了最后一镜，不要单独做退场动画。
- **不用**：滑动、翻转、缩放冲击、故障、闪白（也就是 `SLATE.transition` 的 slide、flip、zoom）。

## 三种结构

1. **手卷游观**（文旅、流程）：开卷（墨退去）→ 镜头横移，地名题签依次钉在山头 → 收卷，题字落印。
2. **一景一句**（诗词、节气）：每镜一景配一句话，景先出、字后写、印最后；镜与镜之间用墨晕串起来。
3. **由景入物**（品牌）：山水大景 → 题出品牌意象 → 浓墨横扫托出行动号召 → 落印。

## 三种开场

1. **墨晕显影**：白纸上一滴墨晕开，画面从中显出，题字紧接着写（`example/index.html`）。
2. **题字先行**：空纸上先写竖排大字，远山随后从下方淡入。适合用一句话立意的片子。
3. **长卷入画**：满屏墨色退去（接上一镜），或者画面一开始就在，镜头从右往左缓缓展开（`example/travel.html`）。

## 三种结尾

1. **落印定格**：最后一个动作是钤印，停 1.5 秒以上（`example/finale.html`）。
2. **留白淡出**：山和月淡去，只留诗句和印（`example/poem.html`）。
3. **墨晕盖满**：墨从画面里的某个物件晕开，盖满整个画面，下一镜用 wash 接上（`example/jieqi.html`）。

不要照搬示例的故事、文案和时长，示例只演示组件的用法。

## 坑（症状 → 修法）

| 症状 | 修法 |
|---|---|
| 同一帧两次渲染有几个像素不一样（字的边缘、印章边缘） | 不要给内容加 SVG `mask`、`filter`；会移动的细线不要用圆头端点（`stroke-linecap: round`）。组件已经避开了这些写法，自己画的元素也照这个规矩来 |
| 画面发灰发脏 | 山的层数减到 3～4 层；把文字挪到留白处；水墨调板不要再叠加颜色 |
| 远山透过近山 | 不要自己给山层设 `mix-blend-mode` 或改透明度；用 `draw(p)` 控制显隐 |
| 颜色不对（青绿的山变成了墨色） | 必须先创建 `SS.stage({ palette })`，再创建其他组件 |
| 画面有残留，或者倒着渲染结果不一样 | 每个组件的 `draw`、`play` 每一帧都要调用，`st.set(t)` 放在 render 第一行 |
| 题签出框 | 不要手动改题签的位置。`SS.marker` 靠近安全区边缘时会自动淡出；如果一直看不到，把它钉的世界坐标往画面中间挪 |
| 竖排的字里有标点 | 组件会自动去掉标点。需要断句就分列（verse 的每列一句） |
| 字压在山上看不清 | 题字放在天空的留白处，或者把山的 `from` / `to` 往下调 |
| 加载变慢 | 每层山、每道雾都在创建时逐像素画好，一层山大约 40～50 毫秒（镜头横移越远，层越宽、越慢），舞台和转场约 80 毫秒。层数不要超过 5；不要在 render 里新建组件 |

## 文化与法务

- 广告片不用"最""第一""国家级""顶级"这类极限用语。
- 诗词要写明作者和出处（题款里写"录王维山居秋暝句"这样的格式）。古诗原文可以用，今人的诗词要有授权。
- 只用组件程序生成的山水，不描摹某一幅具体的传世画作，也不照搬某位画家的构图。
- 不画地图和国界；地名用题签标注即可。
- 示例里的品牌（山岚、松醪）都是虚构的，做片时换成用户的品牌和文案。

## 用法

```html
<link rel="stylesheet" href="/skills/shanshui/style.css">
<script src="/skills/shanshui/components.js"></script>
<script>
  const { seg, u: U, width: W, height: H, ease } = SLATE;
  const st = SS.stage({ palette: 'qinglv', pan: [U * 14, -U * 14], enter: 'bloom' });
  const hills = SS.mountains(st, { layers: 5, kind: 'range', seed: 12, peak: { x: 0.3, layer: 2, h: 2 } });
  const ti = SS.vtitle(st.hud, { x: W * 0.8, y: H * 0.13, text: '高山云雾', size: U * 11 });
  const ins = SS.inscription(st.hud, { x: ti.left - U * 4, y: ti.y + U * 3, text: '明前头采' });
  const se = SS.seal(st.hud, { x: (ins.left + ins.right) / 2, y: ins.bottom + U * 6, text: '山岚', size: U * 7.5 });
  function render(t) {
    st.set(t);
    hills.draw(seg(t, 0, 1.8));
    ti.draw(seg(t, 0.9, 3.0, ease.linear));
    ins.draw(seg(t, 3.0, 3.6));
    se.draw(seg(t, 3.7, 4.05));
  }
</script>
```

- 内容放哪一层：
  - 跟着镜头走的放 `st.world`（梅枝、船）；
  - 固定在屏幕上的放 `st.hud`（标题、题字、题款、印章、题签）；
  - 山、雾、水、月由组件自己放进景物层。
- 标题用 `SS.heading`，它会自动放进安全区左上角；内容放在标题下沿（`heading().bottom`）和字幕区（`SLATE.captionZone.y`）之间。
- 每个组件的参数写在 `components.js` 里各函数前的注释中。
- 完整示例（都可以复制后修改，每个 7～8 秒）：
  - `example/index.html`：茶品牌广告开场。青绿调板，墨晕显影，竖排题字、题款、钤印，手卷横移，飞鸟。
  - `example/jieqi.html`：二十四节气讲解。水墨调板，标题，墨梅生长，三候逐列写出，结尾墨晕盖满。
  - `example/travel.html`：文旅目的地介绍。喀斯特群峰、江面倒影、竹筏和涟漪，长卷横移，地名题签依次钉在山头。
  - `example/poem.html`：诗词意境收尾。绢底，烘云托月，诗句逐字写出，朱文印，留白淡出。
  - `example/finale.html`：酒品牌广告结尾。朱金调板，淡金日轮，浓墨横扫托出行动号召，落印定格。
- **不要用 `top`、`name`、`parent` 当全局变量名**，它们和浏览器自带的全局变量冲突，脚本会报错。

## 组件清单

| 组件 | 作用 | 主要方法 |
|---|---|---|
| `SS.stage(opts)` | 纸底、景物层、内容层、转场层；调板；手卷镜头（pan / lift / zoom）；入场和出场转场 | `set(t)`、`project(x, y, depth)` |
| `SS.inkBloom(st, opts)` | 墨晕转场：cover（盖满）、reveal（显影）、wash（退去），边缘带潮线 | `set(p)` |
| `SS.mountains(st, opts)` | 远山层叠（range / karst / hills）、主峰、点苔远树、层间云雾 | `draw(p)`、`ridgeY(i, x)`、`peakNear(i, x)` |
| `SS.mist(st, opts)` | 单独一道云雾带 | `draw(p)` |
| `SS.water(st, opts)` | 水面：遮住山脚、近山倒影、水纹 | `draw(p)` |
| `SS.moon(st, opts)` | 烘云托月，或者朱金调板下的淡金日轮 | `draw(p)` |
| `SS.stroke(parent, opts)` | 通用毛笔笔触：起笔、行笔、收锋、飞白 | `draw(p)` |
| `SS.inkSweep(parent, opts)` | 浓墨横扫，用作标题和行动号召的底 | `draw(p)` |
