# 竖屏快剪

## 画面

- 画幅固定 9:16（`brief.json` 和 `storyboard.json` 里的 `ratio` 写 `9:16`），按 1080×1920 设计。
- 底色 `#1D1F2B`（深墨蓝），大字用白色。三个亮色：
  - 珊瑚红 `#F25F5C`：痛点、问题；
  - 明黄 `#FFE066`：重点词的贴纸底、行动号召按钮；
  - 靛蓝 `#5B5BD6`：卖点卡片。
- 字体用 `"Noto Sans CJK SC"` 最粗的 900。字要大：钩子大字约 15u，卡片上的数字约 19u。
- 贴纸感：白色描边、深色硬阴影（不要用模糊阴影），略微倾斜（-6°～6°）。每屏最多一处黄色贴纸底（`mark`）。
- **避开字幕区和平台按钮**：
  - 运行时把字幕放在画面 70%～84% 的高度（`SLATE.captionZone`），再往下是平台的文案和按钮，右侧边缘还有点赞、评论按钮；
  - 主要内容都放在 `VT.zone` 里，也就是画面 8%～67% 的高度，左右不要贴边。
- 字幕的样式已经在 style.css 里设好（黄底黑字的大号贴纸），不用自己写字幕。

## 动画

- 第一帧就要有内容：钩子大字在 0.3 秒内砸进来（`VT.hook`，从大缩到正常，带一点旋转）。
- 贴纸、卡片、按钮都用带回弹的弹出（约 0.3 秒），弹出后轻轻晃动或"呼吸"，画面一直是活的。
- 转场 1～2 秒一次，用 `VT.cuts`，每屏可以单独选一种：
  - `punch`：缩放冲击；
  - `whip`：甩镜，从右边甩进来；
  - `cut`：纯硬切。
- 顶部用 `VT.progress` 画分段进度条，告诉观众"后面还有"。

## 节奏

- **0～3 秒必须是钩子**，三选一：
  - 问题："地铁里吵到崩溃？"；
  - 反差：前后对比，比如声波从乱跳变成一条平线；
  - 结果：先给结论或数字。
- 中间每屏只讲一个卖点，一屏一个数字或一句话，1～2 秒一切。
- **最后 2 秒是行动号召**：产品（`VT.badge` 或用户的产品图）加优惠贴纸，再加 `VT.cta` 按钮，按钮停留到片尾。
- 15 秒的广告大约 8～10 屏，可以拆成 2～3 镜；每镜内部用 `VT.cuts` 快切。

## 用法

```html
<link rel="stylesheet" href="/skills/vertical/style.css">
<script src="/skills/vertical/components.js"></script>
```

- 页面主体放一个铺满的 `<div id="stage">`。
  1. 每一屏用 `VT.screen(stage)` 建一个图层，再往这一屏里放组件；
  2. 用 `VT.cuts(屏数组, 每屏开始的秒数, {style})` 编排快切；
  3. `render(t)` 里先调用 `cut.set(t)`，再把 `cut.local(t, i)`（第 i 屏的屏内秒数）传给这一屏各个组件的 `set(lt)`。
  - 跨屏的组件（进度条、声波）直接放在 stage 上，传入 t。
- 位置和字号都是像素，按 `SLATE.u` 和 `VT.zone` 算。`delay` 是组件在屏内晚多少秒出现。
- 组件列表：
  - `VT.hook`：钩子大字，一行一行砸进来，`mark` 指定压黄色贴纸底的词；
  - `VT.sticker`：贴纸标签，可带图标 `icon`；
  - `VT.card`：快切卡片，包括图标、大数字和一行说明；
  - `VT.badge`：产品徽章，没有产品图时当占位，有图时传 `src: '/input/文件名'`；
  - `VT.cta`：行动号召按钮，会呼吸，还有点击波纹；
  - `VT.progress`：顶部分段进度条；
  - `VT.wave`：声波，`set(t, amp)` 里 `amp` 从 1 降到 0 就从吵变安静；
  - `VT.cuts`、`VT.screen`：分屏和快切；
  - `VT.icon`：图标（headphones、mute、battery、bolt、cart、wave、check）。
- 参数和完整示例见 `components.js` 文件头注释和 `example/index.html`。
