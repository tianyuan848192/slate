# 瑞士网格

## 1. 是什么 / 不是什么

**是什么**：一眼能认出来的五个特征。
- 所有元素都落在网格上：横屏 12 栏，竖屏 6 栏。文字一律齐左，右边参差。
- 只有一个信号色（默认瑞士红 `#E30613`，可以换成品牌色），只给这一镜的主角用。
- 字号反差极大：巨型数字或大标题，旁边是小号注释，注释上方压一条细线。
- 大面积留白。不用渐变、阴影、发光、颗粒和圆角。
- 动起来像印刷机：字从裁切框里升起，删除用刀切，线沿着长度长出，数字逐位翻到目标值。

**不是什么**：
- 不是暗场发光的发布会大字：没有光扫，没有渐变底。
- 不是综艺花字：字不飞、不转、不弹。
- 不是数据图表：条和块是版式元素，不画坐标轴。
- 不是包豪斯几何拼贴：不堆三原色几何形。
- 和其他风格的分工：
  - 讲原理、做数据复盘用 editorial；
  - 演示软件界面用 screencast；
  - 多个产品比拼用 arena。

## 2. 适合的题材

| 类型 | 例子 |
|---|---|
| 产品发布、卖点 | 新品开场；卖点三连；规格参数表 |
| 品牌、活动 | 品牌宣传；展会或巡展日程；招聘、开放日海报 |
| 促销 | 限时价格（原价划掉、到手价翻牌）；优惠信息；上市日期 |
| 竖屏短广告 | 信息流广告；一镜一个卖点的快节奏短片；结尾 Logo 落版加行动号召 |

## 3. 画面

### 3.1 网格

舞台 `SW.stage()` 会按画幅自动建网格 `st.G`，所有位置都从网格取。

| | 横屏 16:9 | 竖屏 9:16 |
|---|---|---|
| 栏 × 行 | 12 × 6 | 6 × 8 |
| 左右边距 | 安全区边缘（5%） | 6u |
| 栏间距、行间距 | 2u | 2u |
| 版心上沿 `G.top` | 安全区上沿 + 4.5u（上面是页眉带） | 同左 |
| 版心下沿 `G.bottom` | 开字幕时在字幕区上方 1.5u，不开字幕时在安全区下沿 | 始终在字幕区上方 1.5u（再往下是平台文案和按钮） |

- 取位置的方法：
  - `G.x(c)` 是第 c 栏的左边，`G.w(n)` 是 n 栏的宽度；
  - `G.y(r)`、`G.h(n)` 是行的上沿和高度；
  - `G.box(c, n, r, m)` 返回 `{x, y, w, h}`，可以直接展开传给组件；
  - c、r 从 0 开始，可以写小数。
- 构图：
  - 不对称，但要均衡。常用两种：
    - 左右分版：左 6 栏放文字，右 6 栏放产品或巨型数字；
    - 对角线：大标题在左上，巨型数字或产品在右下。
  - 关键时刻主体至少占画面高度的 1/3。
  - 一镜里元素出齐后，版心的大部分应该有内容或是有意的留白。不要让所有东西都缩在左上角。
- 竖屏还要注意：
  - 文字和按钮只排第 0～4 栏，右边一栏的下半屏会被点赞、评论按钮挡住；
  - 字幕区以下不放任何内容；
  - 页眉、注释和脚注在竖屏上会自动大一档。

### 3.2 色彩逻辑

- 底色有四种（`tone`），整镜选一种，色块上的元素传和色块一样的 tone：
  - `page`：浅灰页面 `#EAE9E5`，默认；
  - `paper`：白纸 `#FFFFFF`；
  - `ink`：黑 `#111111`；
  - `signal`：信号色满版。
- 字的颜色：
  - 正文用墨色；
  - 注释用灰色 `#5F5E5A`；
  - 信号色上的字自动按对比度选黑或白。黑字压在信号色上（叠印）是允许的。
- **信号色只给一个主角**：一个巨型数字、一个色块、一条指针或一个按钮。
  - 同一屏最多一大块信号色，再加一处小标记（编号、指针）；
  - 已经有大面积信号色时，行动号召按钮改用黑色（`color: SW.C.ink`）；
  - 整片不加第二个彩色。产品图本身的颜色不算。
- **换品牌色**：
  - 每一镜都传同一个值：`SW.stage({ signal: '#1F3FFF' })`；
  - 品牌有好几个颜色时，只选辨识度最高的一个；
  - 很浅的品牌色（黄、浅绿）只用来做色块，上面的字自动换成黑字。信号色文字在底色上对比度不到 3:1 时，组件会自动改用墨色；
  - 深色品牌色放在 `ink` 底上发闷时，改用 `page` 底。

### 3.3 字体和字号层级

- 字体（style.css 已经设置好，不要换）：
  - 中文用 `"Noto Sans CJK SC"`；
  - 拉丁字母和数字用 **Inter**，字体文件是 `/assets/fonts/Inter-Variable.woff2`，许可见第 12 节。
- 层级靠字号和字重拉开：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 巨型数字 | 20～70u | 800 | 一镜最多一个，配一行小字说明它是什么 |
| 大标题 | 9～13u | 700 | 最多 2 行，每行不超过 6 个字 |
| 页面标题（`heading`） | 横屏 6u，竖屏 6.6u | 700 | 每页一个，左上角 |
| 卖点名、正文 | 3.6～6u | 700 | |
| 注释（`note`） | 2.4～2.8u | 500，灰色 | 上面一条细线 |
| 页眉、脚注 | 1.7～2.2u | 500～600 | 放在 hud 层 |

- 中文不用负字距。拉丁大字收紧 2%，组件会自动处理。
- 屏上的字不等于旁白：一句不超过 8 个汉字，屏上写阿拉伯数字。
- 不用"最""第一""国家级"等极限用语。性能数字要写测得条件（放在 `footnote` 里）。

## 4. 动画

- **三个常量**：
  - 签名缓动：`SW.E`，也就是 `cubic-bezier(.7, 0, .2, 1)`，慢起、快切、长落定。全片只用它和线性。
  - 三档时长：`SW.T.s` 0.35 秒（小元素），`SW.T.m` 0.6 秒（标题、图框），`SW.T.l` 1 秒（网格、镜头）。
  - 统一入场：从裁切框里升起。**不淡入**。
- **招牌动作**：

| 动作 | 组件和方法 | 适合的内容 |
|---|---|---|
| 裁切升起 | 所有文字组件的 `draw(p)` | 标题、卖点名、注释 |
| 刀切删除 | `cut(p)`：信号色细线划过，元素向中线合拢后消失 | 换掉旧参数；结尾清场；功能"不再需要" |
| 划掉保留 | `strike(p)` | 原价、旧方案 |
| 网格生长、收走 | `SW.stage({ grid: 'build' })`、`st.grid.out(p)` | 开场建立系统；收尾只留海报 |
| 数字翻牌 | `SW.numeral` 的 `draw(p)`：每位从起始数字滚到目标，从左到右依次停住 | 价格、续航、日期、型号 |
| 色块擦出 | `SW.block` | 满版色块、出血色带 |
| 遮罩揭示加推近 | `SW.product` 的 `draw(p)`、`push(q)` | 产品图、照片 |
| 指针滑动 | `list.focus(q)`、`specs.focus(i, p)` | 跟着旁白点名 |
| 色块转场 | `SW.wipe` 加 `SW.layer` | 一镜里换页 |

- **不动的东西**：
  - 页眉、页脚、出处（放在 hud 层，不跟镜头动）；
  - 已经落定的大字和网格。
  - 整片不呼吸、不漂浮、不弹跳、不闪烁，文字不旋转。
- **停留期间保持画面有动静，但幅度要小**：
  - 产品慢慢推近（`push`）；
  - 行动号召的箭头每两拍向前点一下（`cta.pulse`）；
  - 指针移到下一条。
- 一组元素错峰入场，总时长不超过 0.5 秒。

## 5. 节奏

- 每镜 6～10 秒。15 秒的竖屏广告拆成 2～3 镜。
- **阅读时长**：
  - 每段屏上文字连续可见的时间，不少于"汉字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 秒"，也不少于"对应旁白时长 + 0.6 秒"；
  - 标题卡至少停 4 秒；
  - 想加快节奏就少放字，不要提前切走。
- 每 2～4 秒要有一个新事件。元素落定后至少停 1 秒。
- 数字在旁白念到它的时候停住（对齐 `SLATE.captions`），之后至少 0.5 秒不变。
- **冲击次数有上限**：
  - 作用于整个画面的冲击（满版色块擦出、整屏转场）全片最多 3 处，相邻两处至少隔 8 秒；
  - 推镜合计不超过镜头数的 1/3，不要连续三镜往里推。
- 入场的落点对齐配乐拍点，用 `SW.beat(n, bpm)` 算第 n 拍的秒数。tech 配乐 120 BPM，bright 108 BPM，calm 64 BPM。

## 6. 镜头词汇表

镜头只在拍点上动，用签名缓动，动完就停。参数写在 `SW.stage({ cam: [{ at, dur, s, cx, cy, r }] })`。

| 动作 | 表达什么 | 适合的内容 |
|---|---|---|
| 锁定版面 | 版式自己说话 | 大多数镜头 |
| 网格生长 | 一个系统建立起来 | 开场、品牌介绍 |
| 推进一个模块（s 1.3～1.8，中心对准模块） | 细节，系统的单元 | 产品局部、一个关键参数 |
| 横移一栏或一页（只改 cx） | 下一步 | 系列产品、目录、日程 |
| 旋转 90° 后停住（r: 90） | 同一件事换个读法 | 海报变成时间表 |
| 拉远到多个模块（s < 1） | 一个系统，多个产出 | 产品线、系列活动 |
| 色块扫屏 | 翻页 | 一镜两页 |
| 刀切后重排 | 删除、替换 | 旧价换新价、旧参数换新参数 |

推镜之前，先把靠近边缘的文字刀切掉，或者确认推完以后文字还在安全区里（slate-qa 会检查越界）。

## 7. 转场

- **签名转场**：
  - 刀切清场：上一镜最后 0.6 秒把元素依次切掉，下一镜从空网格开始；
  - 色块扫屏：`SW.wipe`，色块盖满的那一刻换页；
  - 硬切：下一镜第一帧就是排好的网格（`grid: true`）。
- 只有第一镜用 `grid: 'build'`，后面的镜头都用 `grid: true`。网格一直在，看起来是同一张版面。
- 不用淡入淡出、模糊、缩放和翻转转场。

## 8. 三种结构、三种开场、三种结尾

**结构**：
1. **发布会式**：网格生长加巨型型号或数字 → 卖点（一镜一个，或者三连）→ 规格表 → 价格和上市信息 → 落版。
2. **一张海报的诞生**：每一镜往同一张版面上加一层（标题、产品、参数、日期），最后一镜拉远看到完整的海报。
3. **编号清单**：01～05 的编号贯穿全片，页眉计数从 01 / 05 走到 05 / 05，每镜一个编号模块。

**开场**：
1. 空页面上落下一个信号色方块，网格从它所在的位置长出来（`gridFrom` 设成方块位置）。
2. 一个巨型数字（型号、价格、日期）占满半屏，旁边一行小字说明它是什么。
3. 先给出完整的成品海报，再刀切拆成一条条规则，倒着讲。

**结尾**：
1. Logo 落版，加口号和网址，行动号召一直留到片尾。
2. 所有元素被刀切掉，只剩空网格和一行字（日期或网址），停 2 秒以上。
3. 信号色满版扫过来，黑色口号压在上面，停 2.5 秒以上。

不要照搬示例的故事、文案和时间点。

## 9. 用户的产品图、Logo 和品牌色

### 9.1 产品图

1. **先判断是哪一种图**：

   ```bash
   python3 -c "from PIL import Image; im = Image.open('input/产品.png'); print(im.size, im.getchannel('A').getextrema() if 'A' in im.getbands() else '不透明')"
   ```

   结果里 alpha 的最小值明显小于 255，说明有透明区域，按抠图处理；否则按照片处理。
2. **透明底抠图**：
   - 写法：`SW.product(w, { ...G.box(7, 5, 1, 4), src: '/input/产品.png', mode: 'cutout', bg: 'paper' })`；
   - `bg` 是底板颜色，可选 `'paper' | 'page' | 'signal' | 'ink' | 'none'`。`none` 表示直接放在页面上，可以压在巨型数字上面；
   - `pad` 是留边，`pos` 是对齐位置（例如 `'100% 100%'` 贴右下）；
   - `over: 0.15` 让产品冲出底板上沿，适合竖屏。
3. **带背景的照片**：
   - 写法：`mode: 'photo'`，照片铺满图框，多出来的部分裁掉；
   - 用 `pos` 对准主体，例如 `'50% 40%'`；
   - `mono: true` 把照片转成黑白，让信号色成为画面里唯一的彩色；
   - 图框按整栏、整行取，不加圆角、描边和阴影。
4. 两种图都可以用 `push(q)` 慢慢推近，幅度 4%～8%（`zoom: [1, 1.05]`）。
5. **禁止**：
   - 不要拉伸变形，也不要改产品颜色；
   - 低分辨率的图，显示尺寸不要超过原图的 1.5 倍。
6. **没有产品图时**：
   - 可以不放产品，用巨型数字或文字撑画面；
   - 也可以自己画一张简洁的 SVG，放进 `scenes/NN/`。只用纯色块，不加滤镜，写明 `width` 和 `height`。
   - 不要把占位框留在成片里。
7. 组件会在加载时把图片按需要的分辨率转成位图，再做推近。PNG、JPG、SVG 都能逐帧稳定渲染。

### 9.2 Logo

- 写法：`SW.lockup(w, { x, y, src: '/input/logo.png', h: U * 10, tagline, url })`。Logo 原样显示，不改色、不拉伸、不加效果，四周留白不少于 Logo 高度的一半。
- 放在什么底上：
  - 深色 Logo 放在 `page`、`paper` 上；
  - 白色或浅色 Logo 用 `tone: 'ink'` 或 `'signal'` 的舞台，或者传 `plate: 'ink'` 给它垫一块黑底。
- 没有 Logo 时，传 `text: '品牌名'`，组件会生成"信号色方块加字标"。
- 大号 Logo 全片只在落版出现一次。其他镜头在页眉写品牌名文字就够了。

### 9.3 品牌色

用户给了品牌色，或者从 Logo、官网截图里提炼出品牌色时，按第 3.2 节的规则替换信号色，整片统一。

## 10. 用法和组件

```html
<link rel="stylesheet" href="/skills/swiss/style.css">
<script src="/skills/swiss/components.js"></script>
<script>
  const { u: U } = SLATE;
  const { lin } = SW;
  const st = SW.stage({ grid: true });            // 第一镜用 'build'；品牌色：signal: '#xxxxxx'
  const G = st.G, w = st.world;
  const fo = SW.folio(st.hud, { items: [[0, '品牌'], [6, '卖点'], [11, '02 / 05', 'end']] });
  const hd = SW.heading(w, { index: '02', kicker: '为什么选它', text: '三个数字' });
  const big = SW.numeral(w, { x: G.x(0), y: hd.bottom, value: '40', unit: '小时', size: U * 20 });
  const fn = SW.footnote(st.hud, { text: '开启降噪时测得', anchor: 'end' });
  function render(t) {
    st.set(t);                                    // 第一行
    fo.draw(lin(t, 0, 0.6));
    hd.draw(lin(t, 0.1, 1.0));
    big.draw(lin(t, 0.8, 2.0));
    fn.draw(lin(t, 2.0, 2.5));
  }
</script>
```

- **约定**：
  - 组件在创建时一次性生成元素；
  - `draw / out / cut / strike` 都接收 0～1 的线性进度，用 `SW.lin(t, 开始秒, 结束秒)` 计算，组件内部统一套签名缓动；
  - **用到的方法每一帧都要调用，不要写在 `if` 里**。`lin` 在开始之前返回 0、结束之后返回 1，所以每帧调用就能保证 `render(t)` 是纯函数；
  - 内容放 `st.world`（跟镜头动）。页眉、脚注、出处放 `st.hud`（不跟镜头动）。
- 不要用 `top`、`name`、`parent` 当全局变量名。
- **组件清单**（参数见 components.js 里每个函数前的注释）：

| 组件 | 作用 |
|---|---|
| `stage` | 舞台：底色、网格线（`grid` 选项可开可关）、镜头 `cam`、hud 层；返回网格 `G` |
| `grid` | 单独计算网格（舞台已经带了 `st.G`） |
| `layer`、`wipe` | 一镜里分页，加色块扫屏转场 |
| `folio` | 页眉：顶部细线加一行小字，按栏位排开（放在 hud） |
| `footnote` | 脚注：测得条件、"示例数据"、"价格以活动页为准"（放在 hud） |
| `heading` | 页面标题：细线、编号、小标题、标题，返回 `bottom` |
| `title` | 大标题：一行一行裁切升起 |
| `text`、`note` | 一段文字；注释行（上面一条细线） |
| `numeral` | 数字翻牌，支持前缀（¥）、单位、小数点 |
| `rule`、`block` | 生长的细线；擦出的色块 |
| `list` | 卖点列表：`cols` 并排模块配巨型数字，`rows` 逐行；信号色指针 `focus` |
| `specs` | 规格参数表：逐行入场、数值翻牌、`swap` 刀切换新值、`focus` 高亮 |
| `product` | 产品图框：抠图或照片，遮罩揭示，`push` 推近，`cut` 刀切 |
| `price` | 价格卡：标签、原价（`strike` 划掉）、到手价（`reveal` 翻牌）、说明 |
| `cta` | 行动号召：实色块、文字、箭头，`pulse` 按拍点一下 |
| `lockup` | Logo 落版：用户 Logo 或字标，加细线、口号、网址 |

- 工具：`SW.E`（签名缓动）、`SW.T`（三档时长）、`SW.lin`、`SW.at`（带缓动的进度）、`SW.beat`、`SW.C`（颜色）、`SW.roles(tone)`、`SW.pickInk(bg)`、`SW.contrast(a, b)`。

## 11. 常见问题（症状 → 修法）

| 症状 | 修法 |
|---|---|
| 倒着渲染或从中间开始渲染时，某个元素状态不对 | 这个元素的 `draw`、`cut`、`focus`、`pulse`、`show` 写在了 `if` 里。改成每帧都调用 |
| 画面像幻灯片：标题加三个要点平铺 | 拉开字号差距：一个巨型元素配小注释，用不对称构图 |
| 信号色到处都是 | 一镜只给一个主角。其余强调用字重和字号 |
| 一屏太空 | 放大主体（巨型数字、产品），不要加装饰 |
| 产品把巨型数字挡住了 | 让产品压在数字的一角，数字至少露出 2/3。产品框移到相邻的栏 |
| 竖屏的按钮、文字被平台图标挡住 | 只排第 0～4 栏，不放进字幕区以下 |
| 照片推近时边缘露出底色 | `zoom` 的起点不小于 1，照片用 `mode: 'photo'` |
| 网格线太抢 | 用 `grid: 'cols'` 只留竖线，或者在 `st.set(t)` 之后调用 `st.grid.dim(0.5)` |
| 大标题挤成很长一行 | 拆成两行，每行不超过 6 个字 |
| 数字翻牌太花 | 默认每位只滚一圈以内。不要加 `spin`，数字不超过 4 位 |
| 自己用 `<img>` 放 SVG 并做缩放时，画面有细微抖动 | 用 `SW.product` 放图（它会先转成位图），或者不缩放这张图 |
