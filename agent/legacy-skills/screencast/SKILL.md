# 界面秀

把软件"录"成一支高级感的演示片：界面是重画的（或者是用户给的截图），镜头像录屏软件一样跟着操作推拉，每一步都看得清。

## 是什么 / 不是什么

- **是**：
  - 一个产品窗口（浏览器、应用窗口或手机）浮在柔和渐变壁纸上，有双层柔和阴影；
  - 光标沿弧线移动、点击时缩一下并放出涟漪；输入框里一个字一个字打出来；
  - 点击前镜头推近，结果出现后用聚光灯、标注气泡点明一句结论；
  - 全片只有一种强调色（通常是产品的品牌色）。
- **不是**：
  - 不是品牌海报（swiss）：这里的主角是界面和操作，不是大字和卖点；
  - 不是数据图解（editorial）：图表只是界面的一部分，讲的是"功能怎么用"；
  - 不是真实录屏：每个像素都可控，镜头可以去任何地方，字在推近时也清楚；
  - 不模仿任何真实品牌的界面、图标或 Logo，不出现真实产品名（除非就是用户自己的产品）。

## 画面

### 舞台和外框

- 每镜先创建 `SC.stage()`，壁纸三选一：
  - `mist`：冷白，默认；
  - `dawn`：暖白，适合生活类、移动端产品；
  - `night`：深色，配深色界面（`theme: 'dark'`）。
- 强调色用 `SC.stage({ accent: '#品牌色' })` 统一设置。整片只用这一种强调色；绿、橙、红只用在界面里的状态标签上。
- 外框用 `SC.frame(st.world, { kind })`：
  - `browser`：浏览器，带地址栏，地址用 `app.example.com` 这类示例域名或用户的真实域名；
  - `app`：应用窗口，标题栏居中写窗口标题；
  - `phone`：手机，带状态栏、前置摄像头开孔和底部横条。
- 外框大小用 `SC.fit({ top, aspect })` 算：在内容区（安全区内、字幕区以上）里居中。主体占画面高度的 60%～75%，不要做成一个小窗口。

### 界面骨架（没有截图时用来搭"示意界面"）

| 部件 | 组件 | 要点 |
|---|---|---|
| 侧栏 | `SC.sidebar` | 5 项以内；当前页高亮，用 `select(i, p)` 切换 |
| 页面标题栏 | `SC.header` | 页面名 + 一行说明 + 右侧 1～2 个按钮 |
| 卡片 | `SC.card`、`SC.kpi` | 指标卡数字会滚动，右下角有迷你折线 |
| 图表 | `SC.chart` | 面积图、折线图、柱状图；柱状图只给一根用强调色（`hi`） |
| 表格 | `SC.table` | 5 行以内；单元格可以是文字、状态标签、头像、进度条 |
| 表单 | `SC.field`、`SC.toggle`、`SC.button` | 字段名放在框上方；开关、按钮都有按下的反馈 |
| 清单、通知 | `SC.checklist`、`SC.toast` | 逐条打勾；通知用弹簧弹出 |
| 生成结果 | `SC.stream` | 像 AI 回答一样逐字流出，最新几个字带淡入 |
| 不重要的文字 | `SC.skel` | 灰色占位条，不要编一大段假文案 |

- 界面字号比真实软件大一些（正文 1.5u 左右），一屏只放讲到的功能，其余用占位条。
- 界面里的人名、数字、产品名都是示例。正式做片时按用户的描述换掉，只展示用户说过的功能，不要虚构。

### 叠加层（观众要读的字都放这里）

- **标题**：`SC.heading(st.hud, { kicker, text, sub })`，默认居中放在安全区顶部。
  - 大标题不超过 8 个字；
  - 外框从 `heading.bottom` 往下排（`SC.fit({ top: hd.bottom })`）；
  - 镜头推近前用 `out(q)` 收起标题，否则标题会压在放大的界面上。
  - 也可以不放标题，让界面自己的页面名当标题（例如看板示例）。
- **步骤条**：`SC.chapter(st.hud, { items: ['选择模板', '填写信息', '一键发布'] })`，悬浮的玻璃胶囊，可以一直留在顶部。
- **标注气泡**：`SC.callout(st, { at, text, side })`。
  - 圆点钉在目标上，引线连到一句话，字不超过 10 个；
  - 气泡跟着镜头走，但字号不随推近变大；
  - 聚光灯打开时用 `tone: 'light'`（白底气泡）。
- **聚光灯**：`SC.spotlight(st, { at })`，压暗目标以外的画面，目标描一圈白边。
- **角标**：
  - `SC.mark(st.hud)`：右上角"示意界面"；
  - `SC.tag`：深色小标签；
  - `SC.speed`：快进标签"▶▶ 4×"，表示这段时间被压缩了；
  - `SC.keys`：快捷键提示，显示在字幕区上方。
- 外框里的界面和截图一样，**不参与 slate-qa 的文字检查**（外框默认带 `data-qa="ignore"`），所以推近时被裁到画面外、压到字幕底下的界面字不会报错。要观众读的字一律放在叠加层，它们照常自检。

### 光标、打字、点击

- 光标：`SC.cursor(st, { keys })`。
  - `keys` 里的 `t` 是"到达"时刻，移动时长按距离自动算（0.45～0.95 秒）；
  - 路径是带弧度的贝塞尔曲线，起步快、落点慢；
  - `click: true` 在到达后 0.08 秒按下：光标缩小 14%，持续约 0.15 秒，落点放一圈强调色涟漪；
  - 按钮跟着按下：`btn.press(SC.pulse(t, cur.clicks[i]))`。
- 手机用 `kind: 'touch'`：圆形触点只在点按前后出现，像真机录屏"显示触点"。
- 点完把光标移到空白处，**不要停在要读的字上**；点输入框时点在文字将要出现的位置右侧。
- 打字用 `field.type(text, SLATE.seg(t, a, b, SLATE.ease.linear), t)`：
  - 每秒 7～10 个字，打字时光标常亮，停下后闪烁；
  - 预览区可以同步显示打出来的字（见 `steps.html`）。

### 前后对比

`SC.compare(fr, { labels: ['旧版', '新版'] })`：

- 往 `cmp.a`（之前）、`cmp.b`（之后）里放截图或界面；
- 分隔线从左往右扫过，"之后"从左边露出来；
- 标签放在叠加层，分隔线扫到时才换。

适合改版前后、手动和自动、优化前后。

## 用户上传了截图（重点）

用户给了产品截图（`/input/文件名`）时，**优先用真截图，不要重画**。这时不标"示意"。

1. **先看图定位**：
   - 用 `slate-look input/文件名 --q "导出按钮大约在图片的什么位置？请给出它左上角和右下角占图片宽高的百分比"`；
   - 把要讲的每个位置都换算成 0～1 的比例坐标。
2. **装进外框**：
   - 网页截图用 `browser`，桌面软件用 `app`，手机截图用 `phone`；
   - 外框的内容区按截图的宽高比来算，截图铺满不裁切（见 `screenshot.html` 开头）；
   - 然后 `const sh = SC.shot(fr, { src: '/input/文件名' })`。
3. **圈出目标**：`const btn = sh.region(fx, fy, fw, fh)`（比例坐标）；单个点用 `sh.point(fx, fy)`。这些目标镜头、聚光灯、标注、光标都能用。
4. **推拉**：`st.camera([{ t, at: btn, zoom: 'fit', max: 2 }], { bound: fr })`。
   - `bound` 让推近后满屏都是截图，不露出窗口外的壁纸；
   - 推近倍数不要超过 `sh.maxZoom()`（原图像素 ÷ 显示像素），超过就糊。1280 像素宽的截图基本不能推近，改用聚光灯和标注。
5. **聚焦和标注**：
   - `SC.spotlight(st, { at: btn })` 压暗其余部分；
   - `SC.callout(st, { at: btn, text: '导出在右上角', tone: 'light' })` 写一句结论；
   - 需要演示操作时，加光标点一下 `sh.point(...)`。
6. **其他用法**：
   - 长截图用 `sh.scroll(p)` 往下滚；滚动时不要同时用 `region` 定位；
   - 两张截图（旧版、新版）放进 `SC.compare` 做前后对比；
   - 手机截图用 `SC.frame({ kind: 'phone' })` 加 `SC.shot`。
7. **不要做的事**：
   - 不要在截图上画假按钮、改数字；
   - 不要把截图里没有的功能讲成有；
   - 截图里有手机号、邮箱这类个人信息时，用一个 `SC.group` 盖一块和背景同色的色块遮住，并在给用户的总结里说明。

## 没有截图时：示意界面

1. 用上面的骨架组件搭一个**示意界面**：
   - 布局贴近这类产品的常见样子，只画讲到的功能；
   - 产品名用用户给的名字；用户没给时用"示例工作台"这类明显的占位名；
   - 网址用 `example.com`。
2. 画面上必须标"示意"：`const tag = SC.mark(st.hud, { text: '示意界面' })`。
   - 数字是占位时写 `'示意界面 · 示例数据'`；
   - 外框从 `tag.bottom` 往下排，不要压住角标。
3. 在给用户的总结里说一句"界面为示意，上传产品截图可以换成真实界面"。

## 动画

- **运动性格**：
  - 签名缓动 `SC.E.glide`（快出慢停），用于入场；
  - 画面内移动和镜头用 `SC.E.move`；
  - 退场用 `SC.E.exit`。
- **三档时长**：
  - `SC.D.fast` 0.25 秒：按下、切换；
  - `SC.D.base` 0.6 秒：入场；
  - `SC.D.slow` 0.9 秒：镜头。
- **统一入场**：窗口和卡片从下方升起，同时由 0.92 放大到 1（`frame.draw(SC.pop(t, 开始))`）。弹簧阻尼比约 0.78，只有轻微回弹。
- 一组元素错峰入场，总时长不超过 0.6 秒；同一时刻只有一个主角在动。
- **什么永远不动**：标题、步骤条、角标、字幕区。界面落定后只有镜头在极缓慢地推（`drift`，默认每秒 0.5%），不要再加呼吸、漂浮。只有收尾镜的界面碎片可以轻微漂浮。

## 节奏

- 每镜 6～10 秒，一镜只讲一个操作或一个结论。
- **每 2～4 秒要有一个新事件**：一次点击、一段打字、一次推近、一个结果出现。落定后至少停 1 秒再做下一件事。
- **阅读时长**：屏上要读的字连续可见的时间，不少于"汉字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 秒"。例如：
  - 标题"一句话生成报表"（7 个字）至少 3.1 秒；
  - 标注"复购率提升 12.4%"约 3 秒。
  - 想加快就少放字，不要提前收。
- 动作对齐旁白：点击、推近、标注出现的时刻对准旁白里说到它的那个词（看 `SLATE.captions`）。

## 镜头词汇表

| 动作 | 表达什么 | 适合内容 |
|---|---|---|
| 全景静止（只缓推） | "这是整个产品" | 开场亮相、收尾总览 |
| 推近到按钮或输入框（1.4～2.2 倍，点击前 0.3～0.5 秒开始） | "就在这里操作" | 新入口、关键设置、一键生成 |
| 推近到结果区（1.2～1.4 倍） | "看结果" | 生成的图表、AI 回答、导出的文件 |
| 推近 + 聚光灯 + 标注 | "记住这一句" | 关键数字、一个承诺（"自动保存"） |
| 横移（同一倍数下移动到另一个区域） | "下一步在这边" | 表单从上往下填、左右两栏 |
| 拉回全景 | "全部完成" | 提交成功、多步完成后的总览 |
| 前后对比扫过 | "变化在这里" | 改版、手动和自动 |
| 页面切换（`SC.swap`） | "进入下一页" | 列表 → 详情、模板 → 表单 |

- 镜头是标点：看得清就不动。
- 快推这类重音动作，合计不超过镜头数的 1/3；不要连续三镜都往里推。
- 推近时目标会被放到内容区中心（安全区顶部到字幕区之间）：
  - 顶部有常驻的步骤条时传 `st.camera(keys, { top: steps.bottom })`；
  - 目标靠窗口边缘时加 `bound: fr`，宁可偏离中心也不露出窗口外的空白。
- 只在镜头快速平移时才出现单轴运动模糊（自动），缓推不模糊。
- **转场**：
  - 一镜内用界面自己的变化当转场：页面切换、窗口升起、前后对比；
  - 镜头之间直接切，切点放在一个动作刚落定之后；
  - 不用淡入淡出当主转场。

## 三种结构

1. **一个任务走到底**：打开 → 三步操作（步骤条 01～03）→ 结果 → 总结。适合教程、上手引导。
2. **三个亮点**：每镜一个功能，"推近 → 结果 → 标注一句"重复三次，最后一镜拉回全景。适合版本更新、功能发布。
3. **问题 → 解法**：先用前后对比或旧流程讲痛点，再演示新功能，最后给数字结果。适合效率工具、改版。

## 三种开场

1. **空状态**：一个空白的输入框，光标闪烁，标题"一句话生成报表"（`index.html`）。
2. **通知弹出**：界面静止，一条通知弹进来（"你有 3 条待审批"），镜头跟着推过去。
3. **前后对比**：旧版截图上分隔线扫过，新版露出来（`screenshot.html`）。

## 三种结尾

1. **行动号召**：产品标记 + 一句话 + 按钮，光标点一下按钮，下方写网址（`finale.html`）。
2. **拉回全景**：从最后一个结果拉回整个窗口，窗口里所有功能都亮着，加一句总结。
3. **完成清单**：清单逐条打勾，最后一条勾上时弹出"已完成"通知。

不要照搬示例的故事、文案和时长，按用户的产品重新设计。

## 坑（症状 → 修法）

- **光标、标注、镜头对不准目标** → 界面布局在创建后变了。
  - 元素的位置、尺寸在创建时就定死；
  - 隐藏用透明度或 `visibility`，不要用 `display:none`；
  - 会变长的字（打字、流式文字）放在固定宽高的框里。
- **推近后标题、步骤条压在界面上很乱** → 推近前用 `heading.out(q)` 收起标题；步骤条本身是悬浮胶囊，可以留着。
- **推近后一半是空壁纸** → 目标在窗口边缘，加 `{ bound: fr }`，或者目标改成几个元素的并集 `at: [a, b]`。
- **截图推近后发糊** → 倍数超过了 `sh.maxZoom()`，降低倍数，或者改用聚光灯。
- **光标挡住了按钮上的字** → 点击位置偏到按钮右侧（`{ el, fx: 0.7 }`），点完移到空白处。
- **"示意界面"角标压在窗口上** → 外框从 `tag.bottom` 开始排。
- **叠加层的字互相重叠** → 叠加层元素的框不要互相重叠（标题、角标、步骤条各占一处）。
- **同一时刻渲染两次、倒序渲染、新开页面渲染结果不一样** →
  - 不要在 `st.world` 里用 SVG `<text>`，界面文字一律用 HTML；
  - 不要删掉 `SC.stage` 每帧做的整层重画，也不要给外框、界面元素加 `will-change`；
  - 自己写的位移、缩放动画用 `SC.tf(x, y, scale)` 生成 transform：没有缩放时位移取整像素，静止时返回 `none`；
  - 隐藏的元素也要每帧把属性设全，不要留着上一帧的值。

## 用法

```html
<link rel="stylesheet" href="/skills/screencast/style.css">
<script src="/skills/screencast/components.js"></script>
<script>
  const { seg, u: U, ease } = SLATE;
  const st = SC.stage({ wall: 'mist', accent: '#3F62F0' });
  const hd = SC.heading(st.hud, { kicker: '新功能', text: '一句话生成报表' });
  const tag = SC.mark(st.hud, { text: '示意界面' });
  const fr = SC.frame(st.world, { kind: 'browser', ...SC.fit({ top: hd.bottom, aspect: 1.72 }), url: 'app.example.com' });
  const side = SC.sidebar(fr, { items: [{ icon: 'home', label: '总览' }, { icon: 'chart', label: '报表' }], active: 1 });
  const input = SC.field(fr, { x: side.w + U * 3, y: U * 10, w: U * 60, icon: 'spark', placeholder: '描述你想看的报表' });
  const go = SC.button(fr, { x: side.w + U * 64, y: U * 10, h: U * 4.6, label: '生成' });
  const cur = SC.cursor(st, { keys: [{ t: 0.9, at: [fr.x + fr.w * 0.8, fr.y + fr.h * 0.9] }, { t: 1.7, at: input, click: true }, { t: 3.6, at: go, click: true }] });
  st.camera([{ t: 3.3, at: [input, go], zoom: 1.4 }]);
  function render(t) {
    st.set(t);                                   // 第一行：镜头、壁纸、整层重画
    hd.draw(seg(t, 0.2, 1.2)); hd.out(seg(t, 3.1, 3.4));
    tag.draw(seg(t, 0.6, 1.1));
    fr.draw(SC.pop(t, 0.1));
    input.focus(seg(t, cur.clicks[0], cur.clicks[0] + 0.2));
    input.type('近 30 天各渠道的销售额', seg(t, 1.9, 3.2, ease.linear), t);
    go.press(SC.pulse(t, cur.clicks[1]));
    cur.set(t);
  }
</script>
```

- 组件的参数写在 `components.js` 每个函数前的注释里。
- 界面组件的父容器可以直接传外框、卡片或分组对象，坐标是它内部的局部坐标。
- 用到的方法每帧都要调用（`draw`、`set`、`press`……），不调用就会停在上一帧的状态。
- **不要用 `top`、`name`、`parent` 当全局变量名**，它们和浏览器自带的全局变量冲突，脚本会报错。

### 组件清单

| 类别 | 组件 |
|---|---|
| 舞台与镜头 | `stage`（`st.camera`、`st.toScreen`、`st.zoom`）、`area`、`fit`、`box` |
| 外框与素材 | `frame`（browser / app / phone）、`shot`（用户截图）、`compare`（前后对比）、`group`、`swap` |
| 界面骨架 | `sidebar`、`header`、`button`、`field`、`toggle`、`card`、`kpi`、`chart`、`table`、`checklist`、`stream`、`toast`、`chip`、`avatar`、`skel`、`icon` |
| 叠加层 | `heading`、`text`、`points`（卖点清单）、`chapter`（步骤条）、`mark`（示意角标）、`tag`、`speed`（快进）、`keys`（按键提示）、`logo` |
| 跟随镜头 | `cursor`（鼠标 / 触点）、`spotlight`（聚光灯）、`callout`（标注气泡） |
| 时间工具 | `pop`（弹簧入场）、`pulse`（按下脉冲）、`E`（缓动）、`D`（三档时长）、`tf` |

### 示例（都可以复制后修改）

- `example/index.html`：新功能发布开场（空状态 → 打字 → 推近 → 图表生成）；
- `example/steps.html`：三步完成一项操作（步骤条、选模板、填表、发布通知）；
- `example/dashboard.html`：看板数据亮点（深色界面、指标滚动、推近 + 聚光灯 + 标注）；
- `example/mobile.html`：移动端功能（手机外框、触点、页面滑入；横竖屏都能用）；
- `example/screenshot.html`：用户截图的前后对比、推近、聚焦、标注。`shot-old.png`、`shot-new.png` 是示例截图，做片时换成 `/input/文件名`；
- `example/finale.html`：收尾行动号召（产品标记、按钮、点击扫光、界面碎片）。
