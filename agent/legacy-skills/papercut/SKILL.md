# 窗花剪纸

画面里的每样东西都是**剪出来、贴上去的一张纸**：细节靠剪掉的部分（镂空、阴线、锯齿口）来表现，体积靠纸影和深浅不同的纸来表现。

## 是什么 / 不是什么

- **是**：
  - 红纸贴在另一种纸上（米纸、靛蓝夜纸、青碧纸）；
  - 镂空的纹样（团花、如意云、回纹、古钱、梅花、锯齿、月牙）；
  - 纸片一格一格地贴上去（12fps）；
  - 折→剪→展把一张纸变成一朵对称的花；
  - 夜里背光一亮，孔里透出暖光。
- **不是**：
  - 国潮平涂：那种风格有描边、渐变和人物造型，这里一律没有；
  - 水墨：这里没有晕染和飞白；
  - 皮影：这里的纸不透光，背光只在关键时刻用一次；
  - 扁平矢量插画：这里没有轮廓线，每块纸片的内部都要剪出东西。
- **适合**：
  - 节庆营销：春节、元宵、端午、中秋，例如年货节开场、品牌拜年、节日限定款；
  - 民俗讲解：窗花为什么对称、春联怎么贴、纹样的寓意；
  - "一变多"的卖点：一次投入多处见效、一个平台连接多方，用折剪展来讲；
  - 收尾祝福和落版。

## 画面

### 色彩逻辑

- **主角永远是中国红纸** `PC.C.red`。用纸色的深浅来分前后和角色，不靠阴影渐变：
  - 远处、压暗用 `far`；
  - 翻过来的纸背用 `back`；
  - 承托或更重的部件（盒盖、底座）用 `deep`。
- **地和主体必须是不同纸族**，否则红压红会糊成一片。地纸用 `PC.stage({ ground })` 选：
  - `rice`：米纸，白天、讲解、促销；
  - `indigo`：靛蓝夜纸，节庆夜景、点灯、收尾；
  - `jade`：青碧纸，端午、清明这类不那么喜庆的题材。
- **远景和地纸同族**：远山默认用地纸族里浅一档的颜色（`hills`），不用红色。
- **金箔全片只用一次**，给一个时刻：金色福字、礼盒丝带，或品牌名的一次金光扫过。金色不能当第二主色。
- **文字的颜色**：
  - 米纸上：标题用红色纸字，正文用墨色；
  - 夜纸、青碧纸上：用米色字；
  - 红纸上（横批、春联、卖点章）：用墨色或米色。
  - 点缀色的面积不超过画面的 5%。
- **示例色板**（只是示例）：红 #D2201F，远 #7E1424，背 #DE3B30，深 #A8161B，金 #D9A93F，米纸 #F2E7D2，夜纸 #1B2546。

### 纸张质感（组件已经做好，自己画纸片时也按这个来）

- **纸纹**：染色不匀、纤维、细点，加载时用固定种子烘焙一次。
- **刀口**：
  - 手剪的低频抖动；
  - 左上亮、右下暗的一道刀边；
  - 没有描边。
- **纸影**：
  - 贴平时偏 (0.25u, 0.35u)，模糊约 0.5u；
  - 悬空时影子拉远、变淡。
- **阴线**：沿外轮廓往里剪一道细缝（`inset`），缝上留连桥。
- **不能有孤岛**：一圈闭合的镂空会让中间的纸掉下来。所以缝都要断开，月牙、花瓣之间都要留桥，卷须要从孔外起笔。
- **纹样全部由程序生成**。不照搬任何剪纸艺人的作品图样，也不在片中点名任何参考作品。

### 字体与文字

| 用途 | 字体 | 许可 |
|---|---|---|
| 标题、春联、横批、福字、印章、卖点 | **马善政楷书 Ma Shan Zheng**（`/assets/fonts/MaShanZheng-Regular.woff2`，3.1 MB，来自 Google Fonts 官方分发的完整字体） | SIL Open Font License 1.1，Copyright 2018 The Ma Shan Zheng Project Authors；许可全文在 `/assets/fonts/MaShanZheng-OFL.txt` |
| 正文、说明、日期、出处 | Noto Sans CJK SC（思源黑体，镜像自带） | SIL Open Font License 1.1 |

- `style.css` 已经声明了 `@font-face`，`components.js` 会在渲染前等字体加载完。场景里不用再引用字体。
- **字号**：
  - 书法标题 6～10u；
  - 正文不小于 3.6u；
  - 出处、角标约 2u。
- **字数**：画面上一行不超过 8 个汉字（春联除外）。屏上只放短文案，长句交给旁白。
- **缺字**：常用简体字都有。生僻字会回落到黑体，大标题里避开生僻字。
- **文字永远在纸片之上**（文字是 SVG，纸片是 canvas）。
  - 不要让纸片从文字上面飞过。
  - 带文字的纸片放在 depth 0。

## 动画

- **签名入场"贴"**：悬空（放大一点、影子拉远）→ 落到纸上 → 轻轻一抖。所有纸片默认都这样入场。
  - 卖点章用 `pop`（转着弹出），印章用 `stamp`（1.6 倍盖下），远山用 `rise`（从下面升起）。
- **一格一格**：
  - 纸片的入场、展开、贴字一律用 `PC.seg(t, a, b)`，它按 12fps 步进；
  - 镜头、光、飘落的纸屑、灯笼摇晃用 `SLATE.seg`，逐帧平滑。
- **三档时长**：快 0.33 秒（4 格）、中 0.67 秒（8 格）、慢 1.25 秒（15 格）。一组错峰入场的总时长不超过 1 秒。
- **签名缓动**：`ease.out`（入场）。出场不单独做，交给转场纸。
- **永远不动的东西**：
  - 地纸只跟着镜头动；
  - 落定的纸片不呼吸、不漂；
  - 文字贴好以后不再晃。
  - 环境动效（飘雪、灯笼轻摇）的幅度远小于主动作。
- **背光**：`glow` 只给 1～2 个主角，而且只在片中的关键时刻亮起，比如点灯、揭晓、收尾。

## 节奏

- **时长**：每镜 6～10 秒，一镜一个主动作。60 秒大约 7～9 镜。
  - 快慢要交替：讲原理的折剪展镜头慢，促销卡、拜年镜头快。
- **阅读时长**：屏上文字连续可见的时长要不少于"汉字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 秒"，而且不少于 1.8 秒；标题卡不少于 4 秒。
  - 想加快就少放字，不要提前切。
  - 文字要在镜头的前半段贴出来，留出阅读时间。
- **新事件**：每 2～4 秒要有一个新事件，比如一张纸贴上、一次展开、一次点灯。纸片落定后至少停 1 秒再接下一个动作。
- **跟旁白对齐**：高亮（`tile` 的 focus、`steps` 的 active）和点灯要对齐旁白点名的那个词，看 `SLATE.captions`。
- **冲击**：`stage({ kicks })` 是落定时的轻震，作用于整个画面。全片不超过 3 处，相邻两处至少隔 16 拍。其他卡点只动主角纸片。
- **镜头**：看得清就不动。缓推、缓拉都控制在 5% 以内，不要连续三镜都往里推。

## 镜头词汇表

| 动作 | 表达什么 | 适合内容 |
|---|---|---|
| 正面平视、锁定 | 纹样就是徽记 | 片名、团花亮相、品牌落版 |
| 缓推（`zoom: [1, 1.04]`） | 注意力收拢 | 讲一个细节、点名一张纹样卡 |
| 缓拉（`zoom: [1.04, 1]`） | 揭示全貌 | 收尾、促销卡全貌、全家福式的布局 |
| 横移加视差（`pan`，远山 depth 设大） | 一路展开 | 时间线、路线、二十四节气 |
| 俯视桌面、纸放大居中（`foldcut`） | 手艺本身 | 折剪展讲原理、"一变多"的卖点 |
| 落定轻震（`kicks`） | 重量、确定 | 福字落下、价格章拍下 |
| 绕团花中心慢转（`flower` 的 `spin`） | 循环、秩序 | 生肖轮转、一年四季、团队 |
| 熄灯只留一处背光（`st.dim` 加 `glow`） | 聚焦、余韵 | 收尾祝福、一个核心卖点 |

## 转场

- **签名转场 `peel`（揭纸）**：一张红纸从角上揭起来。上一镜用 `exit: 'peel'`，下一镜用 `enter: 'peel'`，两镜在全红的那一帧硬切，看起来是连续的一个动作。
- **点缀转场 `cut`（剪开）**：剪刀沿中缝剪一道锯齿，两扇纸向两边拉开，有"开门红"的感觉。适合开场或高潮，全片用 1～2 次。
- **镜内换画面**：`st.cover(q, kind)`，q 从 0 到 1 盖上、从 1 到 2 揭开。在 q 等于 1 的那段时间里切换内容。
- **相邻两镜用同一种 kind 和 `sheet` 颜色**。第一镜可以不用 enter，最后一镜不用 exit。
- **转场占用的时间**：exit 占最后约 0.5 秒，`cut` 的 enter 占最初约 0.65 秒，`peel` 约 0.55 秒。这段时间里不要安排需要阅读的新文字。
- **不要用** `SLATE.transition` 的 fade、blur、zoom，它们不是纸的动作。

## 招牌动作（按内容挑，不必都用）

- **折→剪→展**（`foldcut`）：一次动作变出八份。例如一份配方做出整套口味、一次投入多处见效、窗花为什么对称。
- **孔就是光**（`glow`）：背光一亮，孔里透出暖光。例如一个想法被点亮、夜里亮灯的家、产品的核心技术。
- **团花展开**（`flower`）：从一片楔形一折一折展开。例如品牌开场、一个点扩散成全局。
- **纸屑有去处**（`scraps`）：剪下的纸屑后来变成雪或礼花。例如边角料回收、积少成多。
- **贴春联**（`banner` 加 `couplet`）：品牌口号做成对仗的上下联。春联的贴法是面对门时上联在右、下联在左；上联末字用仄声，下联末字用平声。
- **盖印**（`seal`）：给结论盖章。例如限时承诺、品质认证、落版。

## 坑（症状 → 修法）

- **红压红糊成一片** → 换地纸族；叠在红纸上的部件用 `deep` 或 `far`。
- **夜纸上的红字看不清** → 夜纸上的标题用米色字（`heading` 默认就是）。
- **背光把整片纸提亮成橙色，主角不突出** → `glow` 只给一两个主角。熄灯收尾时，先 `st.dim(...)`，再画要留亮的那一张。
- **同一帧渲染两次结果不同** → 自己写的元素每帧都要把属性设全，包括隐藏时的位置。
  - 不要用 SVG `filter`，它的模糊在不同渲染顺序下会差一个色阶。文字影子用错开的副本（组件已经这样做了）。
  - 不要用 CSS 动画。
- **剪纸纹样中间掉出一块（孤岛）** → 缝要断开、孔与孔之间留桥。自己做纹样时用 `PC.motif` 或 `PC.shape` 拼。
- **翻折看起来像卡片在滑动** → 用 `flower` 或 `foldcut` 自带的折叠（带纸背色和压暗），不要用缩放来模拟。
- **开头或结尾的采样帧几乎是纯色** → 最早的采样点在时长的 1/12 处，那之前要有画面出来；`enter` 的转场要在 0.6 秒内基本揭完。
- **金色到处都是** → 金箔只留一个时刻。
- **广告文案用了"最""第一"这类极限用语** → 改掉。民俗说法措辞要克制，比如"民间常说"；有出处的用 `PC.source` 标出来。

## 变化空间

不要复用示例的故事、文案和时长。

- **三种结构**：
  1. **一年十二剪**：一朵团花分成十二瓣，每讲一个月（或一个生肖、一个节气）转一格、亮一瓣；
  2. **拼装线**：产品由一块块剪纸拼出来，每拼上一块讲一个卖点，最后盖印落版；
  3. **一封折起来的信**：一张折好的纸一格一格展开，每格是一镜，适合品牌故事、家书式的拜年。
- **三种开场**：
  1. **剪开红纸**：`enter: 'cut'`，里面是已经布好的夜景；
  2. **一张空米纸**：`foldcut` 从第 0 秒就开始折；
  3. **满屏窗花已经亮着**：其中一片掉下来，成为这支片的主角。
- **三种结尾**：
  1. **熄灯**：只留一处背光（福字或品牌标）；
  2. **纸屑落定**：撒落的纸屑停下来，品牌名和祝福语贴上去；
  3. **重新折回**：展开的窗花反着折回一个小方块，盖上印章。

## 用法

```html
<link rel="stylesheet" href="/skills/papercut/style.css">
<script src="/skills/papercut/components.js"></script>
<script>
  const { seg: S1, u: U, width: W, height: H } = SLATE;
  const st = PC.stage({ ground: 'indigo', enter: 'peel', exit: 'peel' });
  const h = PC.heading(st, { text: '团圆饭的八道菜', sub: '示例品牌 · 年夜饭' });
  const A = PC.area(h);                                   // 标题下沿到字幕区上沿
  const fl = PC.flower(st, { x: A.cx, y: A.cy, r: Math.min(A.h * 0.45, U * 20), seed: 5 });
  const src = PC.source(st, { text: '示例数据' });
  function render(t) {
    st.set(t);                                            // 第一行：地纸、镜头、转场纸
    h.draw(PC.seg(t, 0.6, 1.4));
    fl.draw(PC.seg(t, 1.2, 3.2), { glow: S1(t, 3.4, 4.0) });
    src.draw(S1(t, 1.5, 2));
  }
</script>
```

- **布局**：
  - 标题用 `PC.heading`，它会自动放进安全区；
  - 内容放在 `PC.area(h)` 给出的区域里（标题下沿到字幕区上沿）；
  - 主体居中、左右均衡，主要图形占画高的 30%～50%；
  - 角标、出处放 `st.hud`（`PC.tag`、`PC.source` 默认就是），它们不跟镜头动。
- **竖屏（9:16）**：字幕区在画高约 70% 处。内容放在 `PC.area` 里，横排的卡片改成 2×2，春联改成一副放在主体两侧的窄条。
- **参数**：每个组件的参数写在 `components.js` 函数前的注释里。
- **示例**（都可以复制后修改；示例里的"示例品牌""示例价格"做片时必须换掉）：
  - `example/index.html`：春节营销开场（剪开红纸、团花展开、灯笼点灯、标题逐字贴上）；
  - `example/folk.html`：民俗讲解（折→剪→展加步骤列表）；
  - `example/promo.html`：节庆促销卡（窗格框、拼出来的礼盒、卖点章、盖印，揭纸出场）；
  - `example/motifs.html`：纹样寓意卡（揭纸入场，逐张点名）；
  - `example/finale.html`：收尾祝福（横批、春联、福字斗方、纸屑、熄灯）。
- **不要用 `top`、`name`、`parent` 当全局变量名**，它们和浏览器自带的全局变量冲突，脚本会报错。

## 组件清单

| 组件 | 用途 | 主要参数和方法 |
|---|---|---|
| `stage(opts)` | 地纸、镜头、转场纸 | `ground`、`zoom`、`pan`、`enter`/`exit`（`peel`、`cut`）、`sheet`、`kicks`；返回 `set(t)`、`cover(q, kind)`、`dim(a, spot)`、`pool(x, y, r, a)`、`world`、`hud` |
| `heading(st, o)` | 书法标题，逐字贴上 | `text`、`sub`、`size`、`align`、`color`、`x`/`y`；返回 `bottom`、`draw(p)` |
| `text(st, o)` | 正文、说明（黑体或书法） | `x`、`y`、`text`/`lines`、`size`、`font`、`color`、`anchor`、`layer`、`shadow` |
| `area(h)` | 内容区 | 返回 `{x, y, w, h, cx, cy}` |
| `steps(st, o)` | 讲解步骤（红菱形编号加短句） | `items`、`gap`；`draw(p, {active})`，p 从 0 到行数 |
| `source` / `tag` | 出处脚注 / 角标（固定在屏幕上） | `text` |
| `piece(st, o)` | 任意形状的纸片（礼盒、鱼、器物……） | `shape`、`holes`、`slits`、`paper`、`motif`、`inset`、`tone`、`enter`、`depth`；`draw(p, {glow, sheen, dim, lift})` |
| `shape` / `tr` / `ring` / `motif` / `merge` | 形状工具和纹样库 | 基本形 `circle`、`ellipse`、`blob`、`rect`、`rrect`、`diamond`、`petal`、`lens`、`crescent`、`tooth`；纹样 `cloud`、`coin`、`fret`、`plum`、`rosette` |
| `flower(st, o)` | 圆形团花，一折一折展开 | `r`、`seed`、`tone`；`draw(p, {glow, spin, dim})` |
| `foldcut(st, o)` | 方纸折三次 → 剪 → 展开 | `size`、`seed`；`set(t, {fold, cut, unfold})` |
| `lantern(st, o)` | 灯笼（垂下、轻摇、点亮） | `r`、`anchor`、`sway`、`pool`；`draw(p, {glow, dim})` |
| `banner` / `couplet` | 横批 / 春联 | `text`、`w`、`h`、`color`；横批贴上，春联卷轴式展开 |
| `fu(st, o)` | 福字斗方（默认金箔字） | `size`、`char`、`color`；`draw(p, {glow, sheen, dim})` |
| `seal(st, o)` | 朱红印章（白文） | `text`（1、2、4 字）、`size`；盖下入场 |
| `badge(st, o)` | 圆形卖点章 | `text`、`sub`、`r` |
| `frame(st, o)` | 窗格边框（框里露出地纸） | `w`、`h`、`band`；返回 `inner` |
| `tile(st, o)` | 纹样卡（纹样加名字加寓意） | `motif`、`name`、`meaning`；`draw(p, {focus, dim})` |
| `hills(st, o)` | 远山（锯齿顶加月牙纹） | `y`、`amp`、`far`、`depth`、`teeth` |
