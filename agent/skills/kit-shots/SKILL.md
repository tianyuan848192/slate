# 镜头模板库

每个模板是一段做好的镜头，挂到场景里就能用。它不是风格：一支片子仍然只选一个风格，模板的配色和字体要改成当前风格的。

## 什么时候用

- **写分镜时**：每一镜先想清楚要表达什么，再看下面的清单有没有对口的模板。有就在分镜这一镜的 `visual` 里写明"用模板 `<id>`"，方便写代码时找。
- **写代码时**：先读 `/.agents/skills/kit-shots/<id>/shot.js` 开头的 `content` 和 `theme`，知道能改什么；再看同目录 `index.html` 的示范用法。
- 没有对口的模板就照常从头写，不要硬套。

## 用法

```html
<div id="main" style="position:absolute;inset:0"></div>
<script src="/skills/kit-motion/kit.js"></script>
<script src="/skills/kit-shots/bar-chart-race/shot.js"></script>
<script>
  const tl = SLATE.timeline();
  tl.add(KIT.shots["bar-chart-race"](document.getElementById("main"), {
    dur: SLATE.duration,                         // 模板按这一镜的时长伸缩：比原设计短就等比压缩，长就把退场放到最后
    content: { title: "主流大模型调用量", ... },   // 只写要改的字段，其余用默认值
    theme: { "--kit-accent": "#E85D5D" },         // 改成当前风格的配色和字体
  }), 0);
  window.render = t => tl.at(t);
</script>
```

- 模板返回一条时间线（`SLATE.timeline`），从 0 秒开始。可以 `tl.add(模板时间线, 秒数)` 放到这一镜的任意时刻，也可以在同一镜里再加别的元素和动作（见 kit-motion）。
- 模板按原设计尺寸（多数是 1920×1080）排版，挂进去会自动缩放居中。原设计是 16:9 的模板放进竖屏会留边，竖屏片子优先选画幅包含 9:16 的模板。
- 带 WebGL 的模板渲染慢（CPU 软件渲染，每帧约 0.5～10 秒），一支片子里少用。它们的 shot.js 是 ES module：页面 `<head>` 里先写 importmap（`"three"` 映射到 `/node_modules/three/build/three.module.js`，`"three/addons/"` 映射到 `/node_modules/three/examples/jsm/`），用 `<script type="module">` 引入，照抄示范页 `index.html` 的写法（包括 `window.READY`）。
- 所有模板都已经避开了底部字幕区。改内容时如果文字变多，注意不要挤出安全区，写完照常跑 `slate-qa`。
