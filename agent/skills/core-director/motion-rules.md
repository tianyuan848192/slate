# 动效原则与转场

适用于所有风格。风格 Skill 里写明的缓动、时长、入场方式和转场，优先于本文件（比如有的风格规定"不淡入"，或者"全片只用一种签名缓动"）；风格没写到的部分，按本文件来。所有动作都要写成 `render(t)` 里关于 t 的函数，见 SKILL.md 第 4 节和 `runtime.md`。

## 1. 四条总原则

1. **顺滑地减速落定，不要弹跳。** 默认用减速曲线（`SLATE.ease.out`，或者更陡的减速）。回弹和弹性只用在明确要俏皮的地方，全片最多一两处。弹跳是让片子显得廉价的头号原因。
2. **跟着旁白揭示，不要一开始就摆满。** 开头只出现旁白此刻说到的东西，其余每个元素在念到它时出现。揭示要分散在整镜里，至少一个关键揭示落在后半段。
3. **宁可不动，也不要乱动。** 不要让卡片、文字一放一缩地循环"呼吸"来显得有活力；不要在镜头后半段加没有落点的慢推、慢摇，那会干扰视线。内容落定后就停住。
4. **衔接处速度要对上。** 镜内换画面、镜与镜交接时，在动得最快的那一刻切，切点两边方向一致、速度相当（见第 7 节）。

## 2. 缓动

| 场合 | 用什么 | 说明 |
|---|---|---|
| 入场、落定（默认） | `SLATE.ease.out`（三次方减速） | `seg`、`stagger` 的默认值 |
| 快速到达、要干脆 | 更陡的减速，比如 `p => 1 - Math.pow(1 - p, 4)` 或指数减速 | 起步冲得快，收尾拖得长 |
| 退场、交接前加速离开 | `SLATE.ease.in` | 慢起快走，把元素"甩"出去 |
| 在两个位置之间移动、镜头运动 | `SLATE.ease.inOut` | 慢起慢停 |
| 进度条、匀速滚动、打字、匀速漂移 | `SLATE.ease.linear` | 只给本来就该匀速的东西 |
| 自然落定、要有物理感 | `SLATE.spring`，damping 调到 20 左右，或设 `overshoot: false` | 不回弹的弹簧 |
| 俏皮的弹出（例外） | `SLATE.ease.back`，或默认参数的 `SLATE.spring` | 只给 Logo、按钮这类小元素，全片一两处 |
| 不要这样用 | 拿 `SLATE.ease.elastic` 做常规入场 | |

- 方向别弄反：入场用减速（out），退场用加速（in）。入场用加速会显得迟钝，退场用减速会显得拖沓。
- 缓动带着情绪：同样一个滑入，陡减速显得笃定，正弦式慢进慢出显得梦幻，回弹显得俏皮。按镜头需要的情绪来选。
- 风格规定了签名缓动时，全片统一用它，靠方向、距离和时长来做出差别。

## 3. 时长

| 档位 | 时长 | 用在 |
|---|---|---|
| 快 | 0.15～0.3 秒 | 按下、强调切换、小图标、退场 |
| 中 | 0.3～0.5 秒 | 大多数文字和卡片的入场 |
| 慢 | 0.5～0.8 秒 | 标题、主图、英雄揭示 |
| 很慢 | 0.8～2 秒 | 镜头运动、图表生长、长线条画出 |

| 动作 | 推荐 |
|---|---|
| 数字滚动 | 1.2～2.5 秒（短于 0.8 秒就看不清在滚），落定后至少停 0.5 秒 |
| 柱子长出、比例条填满 | 0.8～1.2 秒，和配套的数字用同一种缓动，同时落定 |
| 线条或图标画出 | 每段 0.3～0.8 秒；下一段在上一段画到 70%～80% 时开始 |
| 推近到目标 | 1～2 秒（短于 0.8 秒像瞬移，长于 2.5 秒显得拖） |
| 焦点转移（其余部分虚化） | 0.5～1.2 秒 |
| 打字 | 每秒 7～10 个字 |

- 入场比退场慢，比如一张卡 0.4 秒进、0.25 秒出。
- 全片最慢的动作至少是最快动作的 3 倍长。所有东西都是 0.5 秒，就没有节奏了。
- 风格 Skill 给了自己的三档时长（比如 0.35 / 0.6 / 1.0 秒）时，按风格来。

## 4. 错峰和层级

- 一组元素一起出现时要错峰：间隔 0.04～0.1 秒，整组总时长不超过 0.5 秒。用 `SLATE.stagger(t, i, start, gap)`，gap 取 `Math.min(0.08, 0.5 / 个数)`。超过 9 个元素就不再逐个错峰，改成一次擦除或扫过。
- 错峰的顺序按重要性排，不按代码里的顺序：先动的会被看成最重要的。
- 后一个不必等前一个停稳，入场可以互相重叠，像一道波浪。
- 和旁白对应的元素不用错峰：每个在念到它时出现，间隔就是旁白自己的节奏。
- 同一时刻最多两样东西在出现，同一时刻只突出一个重点。
- 层级至少靠两种手段叠加：大小（约 3:1）、字重、明暗、位置、先后、动与不动。只是字大一点、其他都一样的标题，压不住画面。

## 5. 入场、退场、停留

**入场**
- 位移要小：上浮 1～3u，侧滑 3～6u，或者从 0.92～0.96 倍放大到 1。十几 u 以上的大位移只用于整组冲入。
- 一镜里的入场方式要有变化，不要每个元素都"上浮加淡入"。可以换方向，可以从缩放进入，可以只淡入，可以从遮罩里升起，也可以画出来。
- 第 0 帧就要有底色和至少一个锚点元素。第一个动作在 0.1～0.3 秒开始。
- 区间外的状态要夹住：`seg` 在区间之前返回 0、之后返回 1，自己写插值时也不要越界。

**退场**
- 镜头中途元素不退场，除非是被替换（用 `SLATE.transition` 或替换动作），或者在镜尾做交接。
- 退场比入场快，用加速曲线。最后一镜可以整体淡到底色收尾。

**停留**
- 元素落定后，至少停 1 秒再做下一件事；镜头最后的完整画面至少停 1 秒。
- 屏上文字连续可见的时间，不少于"汉字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 秒"。
- 停留是故意安排的，不是失败：高潮之后、转折之前、落版的时候，静止的画面最有力。真正的失败是前 25% 就摆满，然后冻住不动。
- 停留期间只允许一点点"活气"：主体用 `SLATE.noise(种子, t * 0.5)` 做 0.2u 以内的轻微抖动，或者让图标内部有小动作（指针转动、圆点闪烁）。不要整张卡片呼吸，也不要让多个元素各自漂浮。

**别让画面一直在动**
- 每 2～4 秒一个新事件，事件之间是停留，不是连续不断的小动作。
- 背景的环境动效（光晕、网格、粒子）最多一层，幅度小、速度慢；风格不允许时就不加。
- 不要无限循环：所有循环都在本镜时长内结束，并且只由 t 决定。
- `slate-qa` 会在整镜里均匀抽 6 帧，6 帧几乎一样就会报"没动起来"，所以不要在前 10% 就全部摆完。镜尾清场后也要留下底纹或页眉，不要变成纯色，否则会被报空白。

## 6. 一镜的结构：开场 → 搭建 → 停留 → 交接

每镜时长约等于配音时长加 0.8 秒，配音从第 0 秒开始。所以一镜分四段：

| 阶段 | 时间 | 做什么 |
|---|---|---|
| 开场 | 0～0.3 秒 | 第 0 帧已经有底色和锚点；如果上一镜做了交接动作，在这里接上 |
| 搭建 | 0.3 秒～配音快结束时 | 每个元素在旁白念到时出现。时机从 `SLATE.captions` 里找关键词所在那条字幕的 start，提前约 0.1 秒；关键词在一行中间时，按字的位置在 start 和 end 之间插值 |
| 停留 | 最后一个揭示之后 | 完整画面静止至少 1 秒，并且满足阅读时长 |
| 交接 | 最后 0.3～0.6 秒（没有旁白的那段） | 硬切就什么都不做；其他交接方式见第 7 节 |

例子：一镜约 7.2 秒，旁白是"它分三步：先查资料，再写回答，最后标出处。这样每句话都有依据。"（约 6.4 秒配音）
- 0 秒：纸面、标题和三个节点的淡影已经在画面上；
- 约 1.3 秒念到"查资料"：节点 1 上墨；约 2.5 秒念到"写回答"：箭头画出，节点 2 上墨；约 3.7 秒念到"标出处"：节点 3 上墨；
- 约 4.8 秒念到"有依据"：一条强调色的线从"出处"连回"资料"（后半段的关键揭示，不引入新文字）；
- 5.8～6.8 秒：三个节点恢复同样的浓度，整张图静止；
- 6.8～7.2 秒：按约定的方式交接，或者硬切。

常用的镜头结构（时间按 8 秒左右的镜头给出，其他时长按比例伸缩）：

| 结构 | 搭建 | 停留和收尾 | 招牌动作 |
|---|---|---|---|
| 逐步上墨 | 全图淡影 → 每个旁白分句点亮一块 | 全部恢复，静止至少 1 秒 | 淡影变成实色 |
| 大字节拍 | 一句话分 2～4 拍，在原位逐拍替换或累加 | 最后一拍停到结尾 | 原位替换 |
| 数字落地 | 数字从 0 滚到目标（1.2～2.5 秒），比例条同步填满，标签在数字落定前后出现 | 数字静止至少 0.5 秒 | 落定的那一下 |
| 推近细节 | 整体落定 → 留 0.5～1.5 秒让观众扫一眼 → 用 1～2 秒推近到 1.5～3 倍 | 停至少 1.5 秒，之后可以拉回 | 推近 |
| 网格汇聚 | 3～6 张卡错峰拼好（总共不超过 0.5 秒），或者一张卡对应一句 | 停住；可以轻轻拉远露出全貌 | 拼合 |
| 镜头巡游 | 宽画布上排好几个站点，镜头逐站平移（每次 0.8～1.2 秒） | 每站至少停 1.5 秒，最后停在最后一站 | 平移 |
| 锚定轮换 | 主句或品牌名入场后不动，旁边的词每拍换一个 | 换到最后一个后停住 | 锚点不动 |
| 对比分屏 | 两张卡从两侧进入（0.5～0.7 秒），然后逐行对照 | 结论用强调色点明后停住 | 并排对照 |
| 标题卡或喘息卡 | 只有一个克制的动作（上浮淡入或擦出），1.5 秒内完成 | 静止到结尾 | 静止本身 |
| Logo 落版 | 清场 → 标志画出或弹出 → 约 0.2 秒后出字标 → 口号和行动 | 在前 40% 搭完，之后静止 | 标志成形 |
| 镜内换页 | 第一页讲完 → 用 `SLATE.transition` 换到第二页 | 第二页再按上面某种结构走 | 换页 |

复杂的镜头可以用时间线工具按秒排动作。无论怎么写，画面都必须只由 t 决定。

## 7. 转场

### 7.1 两种转场

- **镜内转场**：同一镜里两个画面之间的切换，用 `SLATE.transition(t, A, B, {at, dur, kind, dir})`，kind 可选 fade、slide、wipe、zoom、blur、flip。需要真正的叠化、变形，或者一个元素变成另一个元素时，把两个画面放进同一镜。
- **镜间交接**：成片是把各镜首尾直接拼接起来的，镜与镜之间没有自动转场，默认就是硬切。想要别的效果，要把交接动作拆成两半，分别写在上一镜的最后 0.3～0.6 秒和下一镜的开头 0.3～0.6 秒，两边的方向、距离、时长、颜色都要一致。把交接方式写进两镜的 visual（比如上一镜写"结尾：标题向左加速离开"，下一镜写"开头：标题从右侧接着向左滑入"），写代码时照着对齐。

### 7.2 转场目录

| 转场 | 怎么做 | 时长 | 什么时候用 |
|---|---|---|---|
| 硬切 | 什么都不做 | 0 | 默认选择；节奏快的清单、换话题、让观众"醒一下"；连续几个快切 |
| 同底硬切 | 相邻两镜用同一种底色、同一套网格或页眉，只换内容 | 0 | 让硬切看起来像翻页；讲解片的主体段落 |
| 清场重建 | 上一镜最后 0.4～0.6 秒把元素依次收掉（留下底纹），下一镜在同一张空底上开始搭 | 0.4～0.6 秒 | 一段讲完、换下一段；风格允许的"刀切""收墨" |
| 速度匹配切 | 上一镜主体在最后约 0.3 秒向一侧加速移动约 20u，透明度在前 0.2 秒内降到 0；下一镜主体从另一侧 20u 处、透明度 0.35 起步，0.3～0.4 秒内减速回到原位，运动方向和上一镜相同 | 约 0.3 + 0.4 秒 | 讲同一件事的连续几镜；顺序步骤、连续卖点 |
| 推进穿越 | 上一镜标题在 0.2 秒内放大到 1.2 倍，模糊到约 1u，透明度降到 0.15；下一镜标题从 0.75 倍、同样的模糊和透明度开始，用 0.5 秒强减速长到 1 倍 | 0.2 + 0.5 秒 | 换章节、从钩子进入正题（"往里走"）；只用于大标题和短句 |
| 反向穿越 | 上一镜缩小到 0.8 倍并淡出；下一镜从 1.25 倍缩回 1 倍 | 0.2 + 0.5 秒 | 落到结论、揭晓答案（"到了"） |
| 色块扫屏 | 上一镜最后 0.25～0.4 秒，一块满版色块扫过来盖满画面；下一镜第一帧被同色色块盖满，再朝同一方向扫走 | 0.5～0.8 秒 | 换话题、英雄揭示之前；全片 2～3 次 |
| 经底色淡出淡入 | 上一镜内容淡到底色，下一镜从底色淡入 | 0.3～0.6 秒 | 安静、抒情的段落；片尾 |
| 形状衔接 | 上一镜结尾的某个形状（圆、线、方块）和下一镜开头的某个元素同色、同位置、同大小 | 0 | 概念转化（"这个圆，就是一颗行星"）；讲解片里的巧思 |
| 镜内淡化、模糊、擦除、滑动、翻转 | 用 `SLATE.transition` | 0.3～0.8 秒 | 镜内换页；翻转只用于俏皮的风格 |

- 转场带着意思：叠化是"接着说"，硬切是"注意，换了"，慢慢虚化淡出是"跟我来"。
- 全片选一种主转场（占 60%～70% 的衔接），再加一两种点缀，不要每次都换。
- 按位置选：开场用最有辨识度的那种；相关要点之间用主转场，0.3 秒左右；换话题时用和主转场不同的那种；高潮用最大胆的；片尾回到最简单、最慢的（0.6～1 秒）。
- 按能量定时长：安静的 0.5～0.8 秒，中等的 0.3～0.5 秒，高能的 0.15～0.3 秒。
- 全片定一个前进方向（默认向左，即内容从右边来、往左边走），所有滑动和速度匹配切都遵守这个方向。
- 模糊量：文字一级的元素，峰值约 1u（再大字就糊成一团）；整屏画面约 1.7～1.9u。切点两侧的模糊、透明度和缩放方向必须一致。模糊加在外层容器上，不要加在每个子元素上。
- 穿越过程中不要同时看到两段文字；正文小字不做穿越，只用于标题和短句。
- 风格 Skill 列出了自己的转场时（比如不用淡入淡出、只用刀切和色块），只用它列出的那些。

## 8. 镜头运动

镜头是标点：看得清就不动，默认静止。

- **怎么实现**：把会动的内容放进一个"世界"容器，镜头运动就是改这个容器的 transform。标题、出处、页眉放在不跟镜头动的上层。
- **推近到某一点**：容器设 `transform-origin: 0 0`。缩放 s 从 1 插值到目标倍数，焦点 f 从画面中心 c 插值到目标点 p，每帧设 `translate(c − s·f) scale(s)`（x、y 分别算）。开始时 s = 1、f = c，画面不动；结束时 p 正好落在画面中心。
- 一镜最多一个主要的镜头动作：推、拉、移选一个，或者一组"拉远 → 对焦 → 推近"的多段计划。
- 推近之前先确认：推完后文字仍在安全区里，离边缘 3u 以上，并且不进字幕区。做不到就先把边缘的字收掉。

| 动作 | 参数 | 表达什么 | 用在 |
|---|---|---|---|
| 静止 | — | 让观众读 | 大多数镜头 |
| 轻推 | 1.00 → 1.04～1.15，1～2 秒，inOut | 专注、加重 | 高潮、结论、英雄揭示 |
| 推近目标 | 1.5～3 倍，1～2 秒；布局落定 0.5～1.5 秒后开始；到位后至少停 1～1.5 秒 | "看这里" | 局部、关键参数、按钮 |
| 拉远 | 从局部特写一口气减速拉到全景 | "原来它在这里"、规模感 | 悬念开场、展示广度的收尾 |
| 平移 | 只改位置，0.8～1.2 秒，inOut；每站至少停 1.5 秒 | 下一个、时间在推进 | 时间线、并列的站点 |
| 三段镜头 | 0.88～0.96 倍 → 1.0 倍（0.3～1 秒时开始，用 1～1.8 秒）→ 1.04～1.15 倍（2～4 秒时开始，用 1～2 秒） | 预备 → 揭示 → 推向高潮 | 品牌片的开场或落版 |
| 焦点转移 | 非焦点层模糊 0.3～1.5u，亮度降到 55% 左右，用 0.5～1.2 秒 | 在一群元素里点名一个 | 多元素画面 |
| 冲击震动 | 0.2～0.3 秒内用 noise 抖动 0.3～0.6u，然后归零 | 撞击 | 只配合"砸下来"的动作，全片一两次 |

- 后半段不要加没有落点的慢推、慢摇。要推就有明确的理由（念到关键句时推），推完就停。风格自带停留期极缓推近的（比如每秒不到 0.5%），按风格来。
- 带推镜的镜头合计不超过全片镜头数的 1/3，不要连续三镜都往里推。
- 不用快速甩镜和持续摇晃；3D 倾斜不超过 8～12°。
- 如果要加镜头微漂移，幅度 0.2～0.7u，x、y 用不同频率（约 1 : 1.3）的 `SLATE.noise`。看得出在晃，就是太大了。

## 9. 写进 render(t) 时注意

- 所有状态都从 t 算出来：位置 = 起点 +（终点 − 起点）× `seg(t, a, b)`。不要累加，不要依赖上一帧。
- 随机数在脚本开头用 `SLATE.rng(种子)` 生成好，`render` 里只读取。
- 布局（元素位置、路径长度）在脚本开头算好，`render` 里只改 transform、opacity、颜色和描边进度。
- 同一个元素的 transform 只由一处代码来写。入场动作和镜头推近要叠加时，分别放在父、子两层，免得互相覆盖。
- 多阶段的动作用 `SLATE.sequence` 或 `SLATE.local` 拆开写。
- 和旁白对齐的时间点从 `SLATE.captions` 里读，不要手写死秒数。重新配音后时间会变，读出来的才跟得上。
