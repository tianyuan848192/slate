# 讲解片打法

讲解类写法（知识科普、原理讲解、教程步骤、清单盘点、故事案例、数据故事）通用的打法：讲什么、按什么顺序讲、旁白怎么写、画面怎么配合。每种写法自己的结构和要点在 `genres/<id>.md`，和本文件冲突时以写法文件为准。流程、场景代码、字幕区和自检仍以 SKILL.md 为准，动效细节见 `motion-rules.md`。风格 Skill 里写明的版式、节奏和动效规则，优先于本文件。

## 1. 先找教学主线（写稿之前）

文章是一堆信息，视频要带着观众完成一次理解。**最常见的失败是按原文段落顺序复述**。动笔前先回答下面六个问题，答不上来就说明还没想清楚：

| 要素 | 问自己 | 落到哪里 |
|---|---|---|
| 受众 | 谁在看？他们已经知道什么、不知道什么？ | brief 的 audience |
| 缺口 | 他们困惑什么？为什么现在要关心？ | 开场钩子 |
| 论点 | 看完只记住一句话，是哪一句？写成判断句，不写成题目（写"RAG 是先查资料再回答"，不写"关于 RAG"） | brief 的 summary |
| 主干 | 支撑论点的 3～6 个机制、步骤或要点 | 主体镜头 |
| 证据 | 具体的数字、例子、对比、算例 | 写进 sources.json |
| 落点 | 看完能带走什么：一个原则、一个判断方法或一个行动 | 最后一镜 |

然后对原文重新排序、合并、删减：保留主干，删掉枝节。

## 2. 选一种结构

| 结构 | 适合 | 主体怎么走 |
|---|---|---|
| 概念讲解 | 一个观众半懂不懂的概念、现象或术语 | 点出概念 → 一层层揭开机制 → 落到"所以呢" |
| 流程步骤 | 有明确先后顺序的操作或机制 | 3～6 步，用同一个画面舞台，一镜一步 |
| 清单 | 几个并列的要点（误区、技巧、原因） | 钩子 → N 个分量相当的条目 → 收束；3 条最有力 |
| 故事案例 | 案例、历史、教训 | 起 → 冲突 → 转折 → 结局 → 道理（道理要能推广到别处） |
| 数据故事 | 用一组数字说明一个变化 | 一个反常的数字 → 拆开看构成或趋势 → 原因 → 意味着什么 |

- 怎么选：要讲懂一个概念，用概念讲解；有先后顺序，用流程步骤；几项并列，用清单；有具体案例，用故事案例。
- 结构可以嵌套，但要说清哪层套哪层，比如"概念讲解，机制部分按流程讲"。不要把几种结构的段落拼在一起。
- 主体几乎总是 3～6 镜连续推进，每镜推进一个机制、一个步骤或一个条目。只有一镜的主体讲不懂任何东西。

## 3. 开场钩子（第一镜，3 秒内抓住人）

钩子要打开一个认知缺口，制造张力，或者点出利害。不要用定义开场（"XX 是指……"），不要用原文的小标题，也不要说"大家好，今天聊聊"。

| 打法 | 什么时候用 | 例子 |
|---|---|---|
| 冲击数字 | 有可信的数字能说明利害 | "人类造过的塑料，九成从来没被回收过。" |
| 反问 | 直接制造缺口 | "为什么年纪越大，觉得时间过得越快？" |
| 反常识 | 真相和常识相反 | "多修一条车道，堵车反而更严重。" |
| 戳中困惑 | 观众已经有这个困惑 | "人人都说要分散投资，可没人说清怎么分。" |
| 具象比喻 | 概念太抽象 | "你的注意力是一盏聚光灯，每个 App 都在抢开关。" |
| 点名概念 | 术语本身就是主角，要让人记住 | "这种现象有个名字，叫旁观者效应。" |
| 点名观众 | 受众非常明确 | "做到一半就放弃的菜谱，你收藏了几份？" |
| 设想情境 | 一个思想实验能统领全片 | "想象一种钱，不花掉就会贬值。" |
| 后果利害 | 做错的代价很具体 | "这一步错了，整锅都得倒掉。" |

- 钩子镜的旁白 15～25 字。第 0 帧画面上就要有东西；1.5 秒内，钩子的关键词既要念出来，也要出现在画面上。
- **论点最迟在第二镜说出来**，后面的镜头都是它的证据。
- 钩子说的是观众能得到的理解（"原来如此"），不说原文的术语清单。
- 自检：删掉所有证据镜，剩下的镜头仍然能说出论点；删掉论点镜，片子就散了。

## 4. 排概念、打比方、举例子、做回扣

**排概念**
- 从观众已知的讲到未知的；先讲简单情形，再讲一般情形。
- 一镜只引入一个新概念。新词第一次出现时就解释，之后全片都用同一个叫法。
- 先给框架再填内容：先说"整个过程分三步"，然后一步一镜。
- 用路标词把镜头串起来："第一步……接着……最后"、"问题在于……"、"这就是为什么……"。
- 主体段落用同一个画面舞台：同一张图逐步长大、同一条数轴往前走、同一个容器逐步变化，让几镜连起来像一个连续镜头。

**打比方**
- 从受众的日常里找（报销、快递、做饭、排队）。类比不能比概念本身还难懂。
- 把两三处对应关系明确说出来，例如"检索就像先翻报销制度，生成就像照着制度写回复"。
- 类比有边界的，说一句"类比到这里就不成立了"，免得误导。
- 类比的画面要贯穿全片：开场用过的意象，结尾再回来用一次。

**举例子**
- 带真实数字的算例胜过抽象描述，例如"本金 1 万，年化 5%，10 年后是 16289 元"。
- 例子要专属于这个主题：如果一个道具原样搬进别的片子也说得通，说明它没从素材里来，换掉它。
- 数字和事实要有出处，写进 sources.json；自己算的数要写明算法；用户给了数据，就只用用户的。

**总结和回扣（最后一镜）**
- 回到开场的问题或意象，给出答案。
- 把论点压成一句话，最多再列三个要点。不要在最后一镜讲新内容。
- 讲解片的"行动号召"是一个用得上的判断方法或下一步，例如"下次看到 X，先问一句 Y"。

## 5. 每镜指定一种讲清楚的手法

给每一镜定一个具体手法，不要只写"解释一下"。

| 类别 | 手法 |
|---|---|
| 具体化 | 类比；把抽象变成实物；带真实数字的算例；锚定熟悉的参照物（"相当于 3 个足球场"） |
| 按序揭示 | 一次只揭开一层；从简单到一般；用路标词 |
| 对比 | 前后对比；常识和事实对比；两个方案并排；反例（"这种情况下它就失效了"） |
| 结构 | 三点法；编号清单；一问一答；先给框架再填内容 |
| 证据 | 数据；出处；演示机制运转；因果链（A → B → C） |
| 记忆点 | 回扣开场；一句话提炼；起一个好记的名字；从个例推到原则 |

情绪要有起伏：开场打开缺口（好奇、困惑、意外）→ 点题定向（清晰、期待）→ 主体建立理解（"原来如此"、信服）→ 结尾落地（豁然开朗、满足）。

## 6. 按时长规划镜头

旁白每秒约 4.5 个字，每镜时长约等于配音时长加 0.8 秒，所以 N 镜的片子，旁白总字数 ≈ 4.5 ×（总时长 − 0.8 × N）。

| 时长 | 镜头数 | 旁白总字数 | 结构 |
|---|---|---|---|
| 15 秒 | 2～3 | 55～60 | 钩子（同时点出论点）→ 用一个画面讲透一个点 → 一句结论。不做多步主体 |
| 30 秒 | 3～5 | 115～125 | 钩子 → 点题 → 1 个机制或 2 个要点 → 总结 |
| 60 秒 | 5～8 | 240～250 | 钩子 → 点题 → 3～4 镜主体（同一个舞台）→ 例子或数据 → 总结 |
| 3 分钟 | 18～24 | 720～750 | 钩子加路线图（"这期讲三件事"）→ 2～3 段，每段 4～6 镜，段首提一个小问题，段尾一句小结 → 总回顾加回扣 |
| 多章节长片 | 每章 2～3 分钟 | 每章 500～750 | 见下面 |

- 镜头时长：钩子镜 4～6 秒，主体镜 6～10 秒，总结镜 5～8 秒。单镜不超过 12 秒，讲不完就拆成两镜。
- 镜内每 2～4 秒要有一个新事件：新的一步出现、一处强调、一个数字落定。
- 配完音后总时长和目标差 10% 以上时，删改旁白，不要靠加快动画去凑。
- 每 60～90 秒安排一个"喘息镜"：内容少，画面基本不动，只说一句话，常放在转折之前。

**多章节长片**（超过 3 分钟；单个任务能做的时长和镜头数以平台限制为准）
- 先写完整讲稿再分章。每章 2～3 分钟，像一支独立的小片：章首一张标题卡加一个本章要回答的问题，中间 3～5 个主干镜头，章尾一句小结，再加一句引出下一章的衔接句。
- 开头 20～30 秒给出全片路线图。每章开头重新抓一次注意力，抛出一个新问题或新数字。
- 全片统一风格、配色、音色和转场方式，并保留反复出现的元素，比如同一张总图逐章点亮、页眉上的章节进度"01 / 04"。
- 结尾总回顾时，每章用一句话收住，最后回到开场的问题。

## 7. 旁白怎么写（中文配音）

**长度和节奏**
- 每镜 1～3 句，共 20～50 字。一句不超过 25 字。字幕一行最多约 16 个字（竖屏约 12 个），在标点处换行，所以逗号之间也控制在这个长度，一个短分句正好一行。
- 长短句交替：短句下判断，长句做解释。一句话只讲一件事。
- **按"提示点"写**：每个分句点名一个画面元素，画面就在念到它时出现。比如"先查资料，再写回答，最后标上出处"，三个分句就是三个出现时机。一整句带长定语的话，画面找不到可以对齐的点。
- 一镜的最后一个分句不要再引出新的屏上文字，只做强调或总结；否则最后出现的字会读不完（见第 8 节的阅读时长）。

**口语化**
- 写给耳朵听：多用"你"，多用动词；少用带一长串"的"的定语，少用"进行""实现""对……加以"这类公文腔，不用"之""其""该"。
- 重要信息放在句尾，中文的重音落在句末。"最后决定答案质量的，是检索"比"检索决定了最后答案的质量"更有力。
- 避开同音容易听错的词。专业词第一次出现时，紧跟一句大白话解释。
- 不说空话，比如"赋能""一站式""全方位""深度解析""干货满满"。
- 写完默念一遍，拗口的地方就改。
- 音色：大众科普用亲切聊天类，严肃话题和数据用正式播报类，故事案例用故事电台类。

**数字和符号**（配音按字面念，字幕也显示这段文字）

| 原文 | 旁白里写成 |
|---|---|
| 3:2、1/3 | 三比二、三分之一 |
| 5-8 个 | 5 到 8 个 |
| 10x | 10 倍 |
| 10/14、8:00 | 10 月 14 日、8 点 |
| 12,345 人 | 一万两千多人（画面上写精确数） |
| 不常见的英文缩写 | 第一次出现时加中文说明 |

- 年份、整数、百分比、小数直接写阿拉伯数字即可。
- 一句里最多一个数字。数字前给参照，数字后说含义，例如"5%，也就是每 20 个里有 1 个"。
- 画面可以显示精确值，旁白说取整后的数。

**停顿**
- 需要让观众消化时，在传给配音的文字里加 `<#0.3#>`～`<#0.6#>` 的停顿，放在关键结论或数字之前，一镜最多一两处。分镜和讲解稿的 narration 里不写这些标记。
- 逐字讲解（verbatim）时，旁白一字不改，只按句子切分到各镜，上面的改写规则都不适用。

## 8. 画面怎么讲

**图怎么一步步出来**
- 画面跟着旁白长出来：开头只出现旁白正在说的东西，其他部分在念到时才出现。时机从 `SLATE.captions` 里找关键词所在那条字幕的 start，提前约 0.1 秒。
- 至少一个关键揭示放在镜头后半段。前 25% 就把东西全摆满然后停住，是最典型的"PPT 感"。
- 复杂的图可以先给全图的淡影（不透明度约 20%），让观众看到全貌，再随旁白一块块"上墨"成实色。
- 讲过的部分退为次要（调淡或变灰），正在讲的保持强调。最后全部恢复，让完整的图停住至少 1 秒。
- 一个元素真的要"变成"另一个（节点变成柱子、公式变成结果）时，在同一镜里完成，不要切镜。

**强调**
- 同一时刻只突出一个重点。强调色只给"正在讲的"和"要记住的"。
- 一次用一两种强调手段：变色、加粗、画下划线、画圈、放大 5%～10%。
- 关键数字在旁白念到时落定，之后至少 0.5 秒不变。

**屏上文字的密度**
- 字幕会自动显示整句旁白，所以屏上**不要重复整句**，只放关键词、术语、数字和标签。
- 一屏需要读的字（不含字幕）不超过约 25 个；标签不超过 6 个字；画面标题不超过 12 个字（分镜的 title 字段不超过 10 个字）。
- 每段屏上文字连续可见的时间，不少于"汉字数 ÷ 4.5 + 其他字符数 ÷ 15 + 1.5 秒"。新文字最晚在镜尾前约 3 秒出现。想加快节奏就少放字，不要提前切走。
- 一镜 3～6 个主要元素，主图高度占画面的 30%～50%。构图和字号按 SKILL.md 第 4 节。

**数据图**
- 数字要配一个有分量的图形（比例条、圆环、面积、实物数量），不要让数字孤零零浮在空白里。
- 不用饼图、双坐标轴和六宫格仪表盘。同屏并列的指标最多 3 个。少用网格线和图例，直接在数据旁边标注。
- 同一个概念的几个数字放在同一个画面空间里，只变数值。换了画面样式，观众会以为换了话题。
- 轴从 0 开始，时间按真实间隔排，比例按真实比例画。说明数字含义的标签，在数字落定前后 0.5 秒内出现。

## 9. 讲解片的镜头类型

| 镜头 | 画面 | 适合 | 要点 |
|---|---|---|---|
| 问题卡 | 一句大字问题，或一个对话场景 | 开场钩子 | 问题要具体，答案留到后面 |
| 大数字 | 一个数字占据视觉中心，旁边一行说明 | 冲击数字开场、关键证据 | 滚动 1.2～2.5 秒，在旁白念到时停住 |
| 术语卡 | 术语加一句白话定义 | 点出概念 | 术语用风格的标题字体，定义不超过 15 个字 |
| 类比对照 | 左边是熟悉的事物，右边是新概念，用连线标出对应 | 具体化 | 对应关系逐条连上，一条对应一个旁白分句 |
| 流程图 | 节点按顺序出现，箭头一段段画出 | 流程步骤 | 横屏横排，竖屏竖排；当前步骤强调，其余退为次要 |
| 结构拆解 | 整体淡影 → 一层层上墨 | 架构、组成 | 一层对应一个提示点 |
| 因果链 | A → B → C，每个箭头就是一个"所以" | 机制、为什么 | 最终结果用强调色 |
| 时间线 | 一条横轴，节点依次点亮，镜头可以沿轴平移 | 历史、演进 | 节点按真实间隔排，标签上下交替 |
| 对比双栏 | 两栏等宽，按同一维度逐行对照 | 前后对比、方案比较 | 只比两个；结论用强调色点明一次 |
| 数据图 | 柱子长出、折线画出、圆环填满 | 数据故事 | 一张图一个结论，结论写成标题 |
| 公式拆解 | 公式逐项出现，每一项下面有注释 | 计算、原理 | 一项对应一个分句；最后代入真实数字 |
| 局部放大 | 在整张图上推近其中一部分 | 细节、关键环节 | 推近 1.5～3 倍，停住至少 1.5 秒再继续 |
| 误区纠正 | 错误说法出现 → 被划掉 → 换成正确说法 | 反常识、清单 | 划掉的动作要清楚，旧说法仍然看得清 |
| 编号清单 | 用"01 / 03"这样的编号贯穿，每镜一条 | 清单结构 | 页眉计数随镜头推进，各条目版式一致 |
| 喘息卡 | 一句话，画面几乎不动 | 转折前、段落之间 | 一个克制的入场动作，然后静止 |
| 总结卡 | 回到开场意象，加一句话论点，最多三个要点 | 最后一镜 | 搭好后静止，等旁白念完结论 |

- 全片至少用三种不同的构图（居中、左右分栏、上下分区、通栏条带、三联），相邻两镜不用同一种。
- 竖屏要把左右分栏、三联改成上下堆叠，不要直接照搬横屏的分栏。

## 10. 常见问题和改法

| 症状 | 原因 | 改法 |
|---|---|---|
| 像在念文章 | 按原文段落顺序走 | 回到第 1 节，按论点和主干重排，删掉枝节 |
| 开场没人想看 | 用定义或寒暄开场 | 换成第 3 节里的一种钩子，第二镜就点出论点 |
| 主体讲不懂 | 一镜塞了两三个新概念，或者主体只有一镜 | 一镜一个概念；主体拆成 3～6 镜，在同一个舞台上连续推进 |
| 像 PPT | 一开头就摆满，然后不动 | 跟着旁白逐个揭示，至少一个揭示放在后半段 |
| 屏上全是字 | 把旁白抄到了画面上 | 屏上只留关键词和数字，整句交给字幕 |
| 字一闪就切走 | 最后出现的字离镜尾太近 | 按阅读时长公式倒推出现时间；镜尾的分句不再引出新字 |
| 类比反而更难懂 | 类比离受众太远，或没说清对应关系 | 换成日常类比，逐条说出对应关系和边界 |
| 数字记不住 | 一句话里好几个数，或数字没有参照 | 一句一个数，前面给参照、后面讲含义，再配一个图形 |
| 每镜长得一样 | 构图模板重复 | 至少三种构图，相邻两镜不重复 |
| 节奏平淡 | 每镜的信息量和动作强度都差不多 | 安排喘息镜；高潮镜信息最集中，它前面一镜放慢 |
| 结尾没有落点 | 最后一镜还在讲新内容 | 最后一镜只做回扣和一句话论点 |
| 时长超了 | 按书面阅读估的字数 | 按每秒 4.5 字、每镜 0.8 秒留白重算，删字，不要提速 |
