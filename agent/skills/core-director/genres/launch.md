# 写法：新品发布

**适合**：新产品第一次亮相，比如发布会视频、上市预热、首发广告。

**和产品介绍的区别**：要隆重、要有悬念，全片围绕一次"英雄揭示"展开。卖点少而有力。

先读 `ad-playbook.md`（宣传类通用的结构、文案和落版规则），本文件只写新品发布特有的部分，两者冲突时以本文件为准。写法只管剧本怎么组织；配色、字体、版式和动作由风格决定。

## 1. 先想清楚

- **一句定位**：产品名，加一句"它是什么"。
- **2～3 个卖点**：按"卖点 → 利益"写，最后一个分量最重。
- **证明**：参数、数据、测试结果。只用用户给的，并写明测试条件。
- **价格、上市时间和渠道**：只写用户给的。没给就不写，落版改成"敬请期待"或者只放产品名。

## 2. 结构

悬念或奇观开场 → 英雄揭示（产品名加一句定位）→ 2～3 个卖点（卖点-利益连环）→ 证明 → 价格和上市时间 → 落版。

- 开新品类的产品，可以走"未来场景"的主线：设想一种新的生活方式 → 点出产品 → 痛点消失 → 结果。
- **英雄揭示是全片最隆重的一次**：遮罩揭开加轻推，产品占画面高度的 40%～50%。揭示之前放一处"停"。
- 整屏冲击全片 2～3 处：英雄揭示一处，落版一处，最多再加一处。

## 3. 按时长

| 时长 | 怎么讲 |
|---|---|
| 15 秒 | 钩子 → 英雄揭示 → 落版 |
| 30 秒 | 加上 1～2 个卖点 |
| 60 秒 | 完整结构 |

## 4. 旁白和配音

- 短句，有力。三个卖点用排比，节奏是短、短、长。
- 品牌名或产品名至少说两次：揭示时一次，落版时一次。
- 音色：正式播报类，或者真诚的亲切聊天类。配乐 tech。

## 5. 常用镜头

英雄揭示、局部推近、参数翻牌、卖点标注、Logo 落版（见 `ad-playbook.md` 第 7 节）。

## 6. 风格

用户选了风格就用用户的，结构照样按本文件写。用户没选时，默认用 `film-dark-keynote`。也可以从下面挑：
- 突出实物质感：`film-glass-product`；
- 年轻、潮流：`film-swiss-motion`。

## 7. 常见问题

| 症状 | 改法 |
|---|---|
| 一开头就露出产品，没有悬念 | 把揭示后移，前面用钩子吊住 |
| 揭示不够隆重 | 揭示前放一处"停"，揭示时用全片最大的动作 |
| 卖点太多 | 只留 2～3 个，最重的放最后 |
| 编了价格或日期 | 删掉，只写用户给的 |
