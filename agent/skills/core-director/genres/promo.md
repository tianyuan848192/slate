# 写法：促销活动

**适合**：限时活动、节日营销、开业优惠、满减、预售。

**和别的宣传写法的区别**：核心是"福利 + 期限 + 行动"，越短越好。价格和规则必须准确。

先读 `ad-playbook.md`（宣传类通用的结构、文案和落版规则），本文件只写促销特有的部分，两者冲突时以本文件为准。写法只管剧本怎么组织；配色、字体、版式和动作由风格决定。

## 1. 先想清楚

- **福利**：价格、折扣、赠品，照用户给的原样写。
- **期限**：活动从什么时候到什么时候。
- **参与方式**：一个行动，比如"扫码领券""到店出示"。
- **主推商品**：一到两个。

价格、折扣、期限和规则只写用户给的，一个字都不改。没给的不编。不用"最低价""全网最"这类说法。

## 2. 结构

福利钩子（价格或限时，第一秒就出现）→ 商品亮相 → 1～2 个卖点 → 价格揭示（原价划掉）→ 期限，加行动。

- 节日活动可以把节日元素用在开场和落版，比如春节、中秋，具体怎么画由风格决定。
- 静音也要看得懂：福利、价格和期限都要用大字出现在画面上，不能只靠字幕。

## 3. 按时长

| 时长 | 怎么讲 |
|---|---|
| 15 秒 | 福利 → 商品 → 行动 |
| 30 秒 | 加上卖点和价格揭示 |
| 60 秒 | 可以讲两三款商品，每款一个价格揭示 |

## 4. 旁白和配音

- 快、短、有劲，第一句就说福利。
- 音色：亲切聊天类，或者搞笑吐槽类，情绪可以用 happy。配乐 bright。

## 5. 常用镜头

价格揭示、参数翻牌（倒计时、折扣数字）、商品英雄、Logo 落版（见 `ad-playbook.md` 第 7 节）。

## 6. 风格

用户选了风格就用用户的，结构照样按本文件写。用户没选时，默认用 `film-swiss-motion`。也可以从下面挑：
- 节日：`film-papercut-red`、`film-paper-lantern`；
- 年轻好玩：`film-pictogram-motion`、`film-microgame`、`film-rubber-hose`。

## 7. 常见问题

| 症状 | 改法 |
|---|---|
| 编了优惠或期限 | 删掉，只写用户给的 |
| 行动不清楚，或者有好几个 | 只留一个，写成"动词 + 对象 + 去哪里" |
| 价格不够醒目 | 到手价做成这一镜最大的字，原价划掉放在旁边 |
| 铺垫太长 | 第一镜就给福利 |
