# 写法：数据故事

**适合**：用一组数字讲一个变化或一个结论，比如行业趋势、经营回顾、调研报告的结论。

**和其他讲解写法的区别**：主角是数字。每个数字都要有参照和含义，并且只用可信的数据，或者用户给的数据。

先读 `explainer-playbook.md`（讲解类通用的讲法、旁白和画面规则，尤其是第 8 节的数据图），本文件只写数据故事特有的部分，两者冲突时以本文件为准。写法只管剧本怎么组织；配色、字体、版式和动作由风格决定。

## 1. 先想清楚

- **一个结论**：写成一句判断，作为全片的标题句，写进 brief 的 summary。
- **3～5 个数字**来支撑这个结论，多了观众记不住。
- **每个数字的参照**：同比、环比、和别的对比，或者换算成实物。
- **意味着什么**：这些数字对观众有什么影响，接下来会怎样。

## 2. 结构

一个反常的数字开场 → 点出结论 → 拆开看（构成、趋势、对比，3～4 镜，在同一个图表空间里只变数值）→ 原因 → 意味着什么，或者接下来会怎样。

## 3. 数据规则

- 用户给了表格或报告，只用里面的数字；自己算出来的数字，要写明算法。
- 坐标轴从 0 开始，比例按真实比例画，时间按真实间隔排。
- 一张图只说一个结论，结论直接写成这张图的标题。
- 同一组数据始终用同一种图表，换了样式，观众会以为换了话题。

## 4. 按时长

| 时长 | 怎么讲 |
|---|---|
| 15 秒 | 一个数字，一个结论 |
| 30 秒 | 2～3 个数字 |
| 60 秒 | 完整结构 |
| 3 分钟以上 | 分成 2～3 个问题，每个问题一组数字 |

## 5. 旁白和配音

- 一句话里最多一个数字。数字前面给参照，后面讲含义。
- 画面上显示精确值，旁白说取整后的数。
- 音色：正式播报类。配乐 tech 或 calm。

## 6. 常用镜头

大数字、数据图、对比双栏、时间线、结构拆解。

## 7. 风格

用户选了风格就用用户的，结构照样按本文件写。用户没选时，默认用 `film-dataviz`。也可以从下面挑：
- 等距的信息图：`film-iso-infographic`；
- 带品牌感的年度报告：`film-swiss-motion`。

## 8. 常见问题

| 症状 | 改法 |
|---|---|
| 数字太多，记不住 | 只留支撑结论的 3～5 个 |
| 图表样式换来换去 | 同一组数据用同一个图表空间，只变数值 |
| 只有数字，没有结论 | 每张图的标题写成结论 |
| 数字没有参照 | 加上同比、对比，或者换算成实物 |
