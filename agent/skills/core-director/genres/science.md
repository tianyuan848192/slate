# 写法：知识科普

**适合**：普通人好奇的问题，比如自然现象、身体、动物、生活常识、历史冷知识。观众没有专业背景，看的动机是"有意思"，不是"工作要用"。

**和原理讲解的区别**：原理讲解要讲到机制，看完能复述；科普以趣味为先，讲到"够用"的深度就停，让人记住一个点、愿意转给别人。

先读 `explainer-playbook.md`（讲解类通用的讲法、旁白和画面规则），本文件只写知识科普特有的部分，两者冲突时以本文件为准。写法只管剧本怎么组织；配色、字体、版式和动作由风格决定。

## 1. 先想清楚四件事

| 要素 | 问自己 |
|---|---|
| 好奇点 | 观众会问的那个"为什么"，用他们自己的话写，不用术语 |
| 直觉答案 | 大多数人以为的答案，常常是错的或者只对一半 |
| 真相 | 一句话说清，写进 brief 的 summary |
| 生活落点 | 看完以后，观众在生活里什么时候会想起它 |

一支片子只回答一个问题。素材里有好几个有趣的点时，挑最好玩的一个，其余的删掉。

## 2. 结构

好奇钩子 → 立起直觉答案，再推翻它 → 真相一层层往下讲（2～4 镜，每镜"再往下一层"）→ 生活里的例子或一个小实验 → 回扣开场的问题，加一句"下次你看到……就知道……"

- 每镜结尾留一个小钩子，把观众带到下一镜："可问题来了……""但这还不是全部。"
- 真相的每一层都要比上一层更出乎意料，或者更贴近观众自己。

## 3. 开场

- 用反问、反常识，或者日常场景里的一个异样："你有没有注意过，镜子里的你左右反了，上下却没反？"
- 不用定义开场，不说"今天来科普一下"。

## 4. 深度和准确

- 专业名词全片最多两个，出现时马上跟一句大白话。能用实物比较（"相当于一粒米的重量"）就不用单位换算。
- 简化可以，说错不行：省略的地方说"简单来说"，有争议的说"目前主流的解释是"。事实和数字都要有出处，写进 sources.json。
- 不夸大、不制造焦虑，比如"每天吃这个会致癌"这类说法。涉及健康和安全的建议，只说有可靠出处的。

## 5. 按时长

| 时长 | 怎么讲 |
|---|---|
| 15 秒 | 问题 → 一句真相，配一个最直观的画面 |
| 30 秒 | 问题 → 直觉答案被推翻 → 真相 → 生活落点 |
| 60 秒 | 完整结构，真相讲两到三层 |
| 3 分钟以上 | 拆成两三个连环问题，每个问题都由上一个答案引出 |

## 6. 旁白和配音

- 像朋友聊天：多说"你"，带一点惊讶和幽默，短句多。
- 音色：亲切聊天类；面向儿童的用萌趣卡通类。配乐 bright 或 calm。

## 7. 常用镜头

问题卡、误区纠正、类比对照、局部放大、结构拆解，带实物参照的大数字，回到开场意象的总结卡（见 `explainer-playbook.md` 第 9 节）。

## 8. 风格

用户选了风格就用用户的，结构照样按本文件写，用这个风格的画面元素来表现。用户没选时，默认用 `film-iso-infographic`。内容明显更适合别的风格时，也可以从下面挑：
- 温暖的手绘：`film-watercolor`；
- 儿童内容：`film-crayon-book`；
- 轻松幽默：`film-midcentury-toon`；
- 立体书的翻开感：`film-paper-popup`。

## 9. 常见问题

| 症状 | 改法 |
|---|---|
| 像在念教科书 | 回到好奇点，用观众的问题开场，删掉定义和背景介绍 |
| 讲了好几个知识点 | 只留一个问题，其余的删掉 |
| 简化以后说错了 | 改成"简单来说……"，保留正确的部分；不确定的不说 |
| 结尾没有落点 | 回扣开场的问题，给一个生活里用得上的"下次你看到……" |
