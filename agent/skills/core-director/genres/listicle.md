# 写法：清单盘点

**适合**：盘点几条并列的要点，比如误区、技巧、原因、推荐、对比。

**和教程步骤的区别**：条目之间是并列关系，没有先后顺序；有先后顺序的用教程步骤。清单节奏快、版式统一，很适合竖屏和信息流。

先读 `explainer-playbook.md`（讲解类通用的讲法、旁白和画面规则），本文件只写清单特有的部分，两者冲突时以本文件为准。写法只管剧本怎么组织；配色、字体、版式和动作由风格决定。

## 1. 先想清楚

- **主题**：写成"N 个……"一句话，比如"三个让手机更费电的习惯"。
- **条数**：3 条最有力，一般不超过 5 条；长片最多 7～10 条，分成两组。
- **每一条**：一个短标题，加一个理由或一个具体例子。
- **排序**：最有力的放最后，第二有力的放第一条，中间放其余的。

## 2. 结构

钩子（直接说出"N 个"和观众的利害）→ 第 1 条到第 N 条（每条一到两镜，版式一致，页眉编号"01 / 05"）→ 收束（一句话总结，或者"你中了几条？"）。

## 3. 每一条怎么写

- 标题不超过 12 个字，各条用同一种句式，比如都用动词开头，或者都写成"不要……"。
- 各条的长度和分量要差不多。某一条明显更重要时，把它放在最后。
- 每条一个具体例子，比空泛的解释有用。

## 4. 节奏

- 每条时长接近，形成稳定的节拍。
- 中间安排一处变化，打破单调，比如第三条改用误区纠正的镜头，或者插一个大数字。

## 5. 按时长

| 时长 | 怎么讲 |
|---|---|
| 15 秒 | 3 条，每条一句 |
| 30 秒 | 3～4 条 |
| 60 秒 | 5 条 |
| 3 分钟以上 | 7～10 条，分成两组，组与组之间一句过渡 |

## 6. 旁白和配音

- 干脆利落，每条第一句就是结论。
- 音色：亲切聊天类，或者搞笑吐槽类。配乐 bright。

## 7. 常用镜头

编号清单、误区纠正、对比双栏、大数字；开场可以用卖点网格先把 N 条的标题总览一遍。

## 8. 风格

用户选了风格就用用户的，结构照样按本文件写。用户没选时，默认用 `film-swiss-motion`。也可以从下面挑：
- 综艺节目感：`film-game-show`；
- 复古档案感：`film-halftone-dossier`；
- 图标化、轻快：`film-pictogram-motion`。

## 9. 常见问题

| 症状 | 改法 |
|---|---|
| 各条分量不均 | 合并太弱的条目，或者把它删掉 |
| 条目之间有先后顺序 | 改用教程步骤 |
| 每条讲得太长 | 每条只留一个标题加一个例子 |
| 结尾没有收束 | 加一镜总结，或者向观众抛一个问题 |
