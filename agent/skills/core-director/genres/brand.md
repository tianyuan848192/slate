# 写法：品牌故事

**适合**：品牌形象片、企业宣传片、城市和文旅宣传、老字号的品牌片、公益片。

**和别的宣传写法的区别**：卖的是态度和认同，不是具体功能。情绪优先，信息少而精，画面和音乐的分量比别的写法重。

先读 `ad-playbook.md`（宣传类通用的结构、文案和落版规则），本文件只写品牌故事特有的部分，两者冲突时以本文件为准。写法只管剧本怎么组织；配色、字体、版式和动作由风格决定。

## 1. 先想清楚

- **价值主张**：品牌相信什么，一句话，写进 brief 的 summary。
- **谁会认同**：目标人群。
- **三个印证**：可以是场景、人群、数字或历史。
- **口号**：用户给了就用用户的，原样不改。

## 2. 结构

情境共鸣（一个让目标人群点头的瞬间）→ 价值主张 → 三个印证（锚定轮换：品牌名或主句不动，旁边的场景、人群轮流替换）→ 情绪高点 → 口号落版。

不同题材的变体：
- **城市和文旅**：一种独特的感受开场 → 三个地方或三个时刻 → 邀请（"来……"）；
- **有历史的品牌**：沿时间线走，起点 → 一直坚持的东西 → 今天 → 口号。

## 3. 旁白和节奏

- 旁白少而有分量，多留白。总字数可以比别的写法少 20%～30%，把时间留给画面和音乐。
- 可以用诗化的短句，但每句都要具体：具体的地方、动作、东西。不用"匠心""赋能""传承百年"这类空话。
- 节奏型一般是"慢-慢-快-停"，喘息镜可以多一些。

## 4. 按时长

| 时长 | 怎么讲 |
|---|---|
| 15 秒 | 一个共鸣瞬间，加口号 |
| 30 秒 | 共鸣 → 价值主张 → 一两个印证 → 口号 |
| 60 秒 | 完整结构 |
| 3 分钟以上 | 按时间线或者三个篇章展开，每篇章一个印证 |

## 5. 配音

音色用故事电台类或者正式播报类。配乐：高端、人文用 calm，年轻品牌用 bright。

## 6. 常用镜头

锚定轮换、时间线、英雄画面、喘息卡、Logo 落版（见 `ad-playbook.md` 第 7 节）。

## 7. 风格

用户选了风格就用用户的，结构照样按本文件写。用户没选时，默认用 `film-swiss-motion`。也可以从下面挑：
- 人文和传统：`film-ink-wash`、`film-papercut-red`、`film-paper-lantern`；
- 城市和文旅：`film-urban-sketch`、`film-silkscreen-poster`、`film-tilt-shift`。

## 8. 常见问题

| 症状 | 改法 |
|---|---|
| 全是空话套话 | 每句换成具体的地方、人、动作或数字 |
| 信息塞太多 | 删到三个印证，给画面和音乐留出时间 |
| 没有落点 | 最后一镜只留口号和品牌，停住 2 秒以上 |
