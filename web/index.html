                            Skills 仓库

                            一支片子由两件事决定：写作方法决定剧本怎么组织，画风决定画面长什么样。两者是两回事，新建视频时各选各的，可以自由搭配。都来自 Slate 官方库。

                            写作方法

                            决定叙事结构、开场和节奏。新建视频时在描述下面选一种，不选就由 Agent 按描述判断。

                            画风

                            决定配色、字体、镜头节奏、转场，以及动画怎么做。任何写作方法都能配任何画风，比如「知识科普」配像素游戏画风。
